# BookReading

![](./assets/readme/hero.svg)

Windows 桌面全格式阅读器（Tauri + React + Rust）：EPUB / TXT / 漫画文件夹·CBZ / PDF，一个应用读完全部藏书；支持登录 wenku8 账号，把云端轻小说书架整本拉取到本地阅读。书籍、进度、笔记全部存在本机；云书架仅在登录后访问你的个人账号数据。

「碳墨刊头」界面：默认**纸墨**主题（米白纸底 × 碳墨单墨），另有**墨夜**与原六主题共 8 套可选，书架、弹窗、正文三处同步换墨。

## v3.2.1 新变化

- **启动画面与进书加载**：打开应用先看到「图标 + 标题」的启动画面，书架随后整体浮入；进入一本书时是翻动的书页加载动画，内容就绪后平滑接上，纸面不再跳动
- **翻到头有提示**：漫画 / PDF / EPUB 翻到首尾再翻，屏幕正中淡入一枚小胶囊（「已是最后一页」/「已是第一页」），一秒自动消失
- **修复详情页「移入回收站」实为永久删除**：现在确实进回收站，可以恢复
- **打开书更稳**：插图优化副本损坏时自动回落原书并在下次启动重做；改名成 .epub 的普通文件、截断的压缩包不再能入库
- 插图与封面按 EXIF 方向转正，不同目录的同名插图各用各的尺寸；TXT 新增识别无 BOM 的 UTF-16，个别坏字节不再让整本乱码
- 内存与细节：每开一本书泄漏的插图 / 字体缓存在关书时释放；夜间主题下漫画折页翻页不再透出新页；更新安装包、导入中断留下的半截文件在启动时自动清理
- 沿用 v3.2.0：EPUB 翻页动画四种效果；设置居中浮窗、默认阅读设置、书库体检批量处理

## 功能总览

### 格式与阅读
- 四种格式统一入口：EPUB、TXT（自动探测 GBK/UTF-8/UTF-16 编码，legado 规则池自动分章）、漫画文件夹与 CBZ（Webtoon 连续滚动）、图片型 PDF 按漫画交互（条漫/页漫），阅读设置与漫画各自独立记忆
- 翻页 / 滚动双阅读模式；单双栏分栏（含日漫封面独占的双页偏移）；RTL（日漫从右向左）；横图跨页检测
- 八套主题：纸墨（默认）/ 墨夜 / 浅色 / 纸黄 / 护眼绿 / 灰 / 暗色 / 高对比暗色，全局即时切换，另可设置自定义背景图与自定义正文字体（ttf/otf/woff2）
- 字号 / 行距 / 字体（宋 / 黑 / 楷 / 仿宋 / 默认悦读栈）自由调节；EPUB 翻页动画四选一（平移 / 覆盖 / 渐隐 / 纸页翻动），速度可调（150–600ms）【v3.2.0】
- 页码显示：EPUB 章内页码 + 全局估算页码；漫画与 PDF 显示第 N / 总页；翻到首 / 末页再翻有轻提示【v3.2.1】
- 沉浸模式：Ctrl+D 锁定全藏界面，鼠标活动不唤出；F11 窗口全屏独立开关
- 漫画：Ctrl+滚轮 0.5–4x 缩放（光标锚点）、拖拽平移、条漫宽度三档 + 自定义、自动滚动（空格播放，方向键调速）
- 划线高亮 / 书签（含章节标题）/ 收藏句子 / 划选复制 / 书内全文搜索（结果带章节标题与百分比，一键跳转）；内置朗读（TTS）与排版细项（字重/字间距/段距/缩进/页边距/两端对齐），排版按书记忆【v2.6.0】


### wenku8 云书架【v3.0.1】
- 登录 wenku8 账号同步云端书架（账密仅存本机）；书卡详情（简介 / 目录 / 标签 / 网页版入口）
- 整本拉取入库：并发下载 + 逐章进度 + 封面 / 简介 / 标签落库；已入库去重 + 「有新章」提示；收藏序 / 最近更新 / 书名排序

### 书库管理
- 层级书架（无限嵌套，侧栏树形导航 + 快捷过滤「全部藏书/在读/未读」，面包屑定位，拖拽归架）
- 标签系统：8 色标签、多选 AND 筛选、批量打标、标签合并；书库体检（重复/失链/悬空封面，勾选批量处理、只确认一次）【v2.6.0 / v3.1.9】
- 回收站：删除先入回收站，7 天 / 30 天 / 永不三种保留期；可恢复、彻底删除（只清书库记录），或「**从电脑删除**」把源文件 / 漫画源文件夹移入 Windows 回收站（文件夹漫画为原地引用，彻底删除不动源目录，从电脑删除才会真删）；书与书架卡可拖到侧栏“回收站”直接删除（回收站页内不启用）
- 批量操作：多选移动 / 收藏 / 删除 / 打标签
- 排序（最近阅读 / 书名 / 导入时间 / 自定义 × 升降序）、阅读状态筛选、搜索（书名 + 文件名，跨书架全库）
- 书籍详情页：编辑标题 / 作者 / 简介，阅读时长 / 格式 / 大小 / 进度 / 书架路径，一键更换自定义封面
- 卡片密度三档（标准 / 宽松 / 特大）、书架四宫格封面缩略

### 导入
- 文件多选导入（EPUB / TXT / PDF）；父目录一键批量导入漫画（每个子文件夹一本书）
- 漫画元数据：文件夹 / CBZ 名形如“[作者] 标题”自动拆分作者与标题（前导“(汉化组)”段忽略；无中括号按原名导入）
- 拖入窗口即导入（支持文件与目录，绝对路径直取）
- 自动查重（文件名 / 标题 + 字节数），四类结果汇总：成功 / 已存在 / 疑似重复 / 失败原因；单本导入命中疑似重复时询问是否导入副本，批量跳过项可一键补齐全部副本
- 入库校验：不是 EPUB 的文件（改名的普通文件、截断的压缩包、其它 zip 格式）直接拒收【v3.2.1】
- 壳级进度条：第 i / N 本 + 当前书名

### 存储与导出
- 书库根目录可迁移（空间预检、复制式迁移、失败自动回滚），迁移完成后可一键删除旧位置文件释放空间
- 占用统计：书籍 / 封面 / 背景图 / 数据库 / 日志分类列表；一键清理：封面缓存、背景图、运行日志
- 标注与收藏摘录一键导出 Markdown（单书 / 全库）

### 窗口与托盘
- 窗口记住大小与位置；点 ✕ 弹三选：最小化到系统托盘 / 退出 / 取消；托盘左键恢复，右键菜单“显示主窗口 / 退出”
- 设置浮窗：八个分区即改即存（外观 / 阅读 / 书库 / 云书架 / 网络与更新 / 快捷键 / 漫画增强 / 关于）【v3.1.9】
- 启动画面（图标 + 标题）与开场浮入，只在冷启动播一次；托盘唤起、切页不重播【v3.2.1】
- 应用内更新：发现新版本后一键下载、安装并重启；启动时静默检查，发现新版在设置入口提示【v3.1.0】

## 安装

从 [Releases](../../releases/latest) 下载 NSIS 安装包（如 `bookreading_3.2.1_x64-setup.exe`，以 Releases 最新为准），双击安装即可。安装包约 6MB；系统缺少 WebView2 运行时（Windows 10 / 11 一般已自带）时安装程序会联网补装。升级安装保留书库与全部数据（升级前建议备份 `%APPDATA%\com.root.bookreading`）。

## 从源码构建

环境要求：Node.js 18+、Rust stable（含 Windows MSVC 工具链）。

```bash
npm install
npm run tauri dev    # 开发调试（前端 dev server 固定占用 14200 端口）
npm run tauri build  # 产出 NSIS 安装包
```

说明：

- cargo 走 rsproxy 镜像拉取 crates——项目已自带 `src-tauri/.cargo/config.toml`，无需手动配置。
- Rust 编译产物体积大，建议把构建目录重定向到大容量磁盘，避免撑爆系统盘：

```bash
CARGO_TARGET_DIR=D:/cargo-target/bookreading npm run tauri build
```

- 跑测试：`npm test`（前端 Vitest，54 文件 375 用例）与 `cd src-tauri && cargo test`（后端）。

## 项目结构

```
bookreading/
├── src/                # React 前端
│   ├── app/            #   路由
│   ├── pages/          #   书库 / 收藏 / 云书架 / 阅读器页面
│   ├── library/        #   书架、标签、导入、封面、密度
│   ├── settings/       #   设置浮窗的分区与通用控件

│   ├── tauri/          #   invoke 封装与前端日志
│   └── ui/             #   AppShell、主题、图标、对话框、设置浮窗

└── docs/               # 设计规范、开发计划、更新日志与验收证据
```

## 已知限制

- 云书架依赖 wenku8 第三方公益中继（wenku8-relay.mewx.org），其可用性不受本应用控制；已拉取到本地的书不受影响

- PDF：文本搜索与划线标注暂不可用，仅支持阅读 / 跳页 / 缩放 / 书签；受密码保护的 PDF 暂不支持。
- EPUB 全局页码为位置估算（按 1024 字/页折算），章内页码准确。
- 条漫深度恢复为近似落位（恢复到最近渲染锚点，不逐像素还原）。
- mobi / azw3 暂不支持（纯 Rust 生态暂无可用的 KF8 解析方案，评估记录见 `docs/superpowers/plans/`）。
