# v3.0.1 · 2026-11-20 · wenku8 云书架

> 本版本 = v3.0 全部功能 + 七轮实机验收打磨，直接以 3.0.1 发布（跳过 3.0.0 号段）。

## 新功能：wenku8 云书架

- **登录即同步**：设置侧「云书架」登录 wenku8 账号（账密仅存本机），云端书架一键投射到桌面
- **拉取到书库**：点书卡看详情（完整书名/作者/状态/简介/卷章目录），选目标书架（下拉内可**新建书架**）后整本拉取——并发下载、逐章进度、自动入库；封面/标签/简介一并落库（标签直接进本地标签系统）
- **已入库去重**：拉过的书显示内联徽标，一键「打开」不再重复导入；连载书懒比对最新章，有更新显示「有新章」
- **排序与密度**：收藏顺序 / 最近更新 / 书名三档排序；密度与书架同一设置联动
- **会话缓存**：切页即回不重拉；顶栏搜索框直接过滤云书架
- **登录管理**：上下文行显示账号与同步时间，一键退出/切换账号；每本书详情可直开网页版

## 界面与体验（验收七轮打磨）

- **切页闪烁根治**：侧栏壳提升为路由级常驻实例（AppLayout + pageMeta），切书架/收藏/云书架/回收站侧栏与底部按钮零重挂载
- **侧栏底部动作区**：刷新/导入漫画/导入图书/设置四钮全局常驻（同款样式，导入钮主题色实底）；刷新行为随当前视图；导入自动落当前书架
- **侧栏上下文行**：四视图同高一行，各显其用（书库=状态筛选 chips、收藏=概览、回收站=保留期、云书架=账号·同步时间）
- **顶栏统一**：四视图标题同字号、搜索框恒定位；云书架搜索框与书架同位
- **继续阅读重设计**：无边框索引行样式，设置中可开关；回收站不再显示
- **云书架详情对话框**：与书库详情同一套纸面设计语言
- **修复**：TXT 导入封面丢失、txt→epub 内嵌标题与书架不同源、书架下拉超长不可滚动、深色主题下拉看不清、设置弹窗打开滚底与滚动条溢出圆角
