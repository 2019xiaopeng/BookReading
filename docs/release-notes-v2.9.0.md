# BookReading v2.9.0

库管理进阶：侧栏折叠、批量选择升级、智能标题清洗。主题词：**书架再多也放得下，名字再乱也能理清**。

## 更新内容

- **侧栏书架树折叠**：有子书架的节点行尾折叠箭头（点名进入、点箭头折叠，互不干扰）；「全部收起 / 全部展开」一键切换；折叠状态跨重启记忆；长树自动滚动不挤底栏
- **Shift 范围多选**：书架 / 回收站 / 收藏页三处——普通点击选中，Shift+点击范围全选（范围内已全选则全不选），清大批量时少点几十下
- **智能标题清洗**：设置→存储「重新清洗全部标题」——预览 diff 确认后一键应用；自动解码 `&#124;` 等 HTML 实体、剥离 `[DL版][汉化组]` 发布标签、`【水印】` 前缀、`(COMIC#N)` 出处后缀、拆分 `｜` 双语标题（中文段入副标题）、清理作者括号注。手动改过名字的书自动跳过；新导入的书自动清洗。剥离的标签在详情页可查
- **鼠标侧键逻辑回溯**（实验性）：侧键后退=走逻辑层级（漫画→其书架→父书架→根）而非浏览器历史栈，两下退出不再穿回前一本漫画。需真鼠标实测，若行为异常请反馈

修复若干（含 v2.8 的目录锚点匹配）。
