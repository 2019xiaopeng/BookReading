# BookReading 功能清单（v2.5.x 全量）

> 权威功能库存清单：应用当前能做的每一件事。标注【v2.5.0+】的是 2026-10 批次 20–26 开发周期及之后补齐的功能，其余为 v2.0/v2.1 已有。
> 按批次的过程记录见 `docs/superpowers/plans/` 与 `docs/CHANGELOG.md`；本文只按用户视角归组。

## 1. 格式与导入

| 功能 | 说明 |
|---|---|
| EPUB 阅读与导入 | 复制入库（library/books/{id}.epub），封面自动提取 |
| TXT 智能导入 | 编码探测（BOM/UTF-8/UTF-16/GBK 回落）→ legado 规则池分章 + 兜底切块 + 超长章拆分 → 转 EPUB3 全链路复用 |
| 漫画文件夹 | 原地引用（不复制），目录 mtime 失效缓存【v2.5.0+】；源目录移动/丢失后可"重新链接"找回 |
| CBZ | 复制入库 + zip 句柄常驻复用（翻完整本 O(N²)→O(N)）【v2.5.0+】 |
| 图片型 PDF | pdf.js 渲染，按漫画交互（条漫/页漫）；位图 useEffect 化不再整页重绘【v2.5.0+】 |
| 拖入窗口即导入 | 文件与目录、OS 拖放绝对路径直取 |
| 批量导入 | 父目录一键扫描子文件夹漫画；壳级进度条（第 i/N 本 + 当前书名）；导入落当前书架 |
| 自动查重 | 文件名/标题 + 字节数双键；四类结果汇总（成功/已存在/疑似重复/失败），单本可导副本、批量可一键补齐 |
| 魔数嗅探 | 错误消息带源路径与 GBK 指引 |

## 2. 书库管理

| 功能 | 说明 |
|---|---|
| 层级书架 | 无限嵌套，侧栏树形导航、面包屑定位、书架四宫格封面卡 |
| 拖拽归架 | 书卡↔书卡（自定义排序）、书/书架→面包屑、→网格书架卡、→侧栏"回收站"删除 |
| **拖到侧栏书架直接移动**【v2.5.0+】 | 书拖到侧栏任意书架=移入；书架卡拖到侧栏=挂为其子书架；拖到「书架」根=移回根层。自身/父级/成环全部拦截（提示高亮 + 后端校验） |
| 侧栏快捷过滤【v2.5.0+】 | 全部藏书 / 在读 / 未读 chips，与状态过滤菜单同源联动 |
| 标签系统 | 8 色标签、多选 AND 筛选、批量打标、标签合并、管理弹窗 |
| 回收站 | 软删→保留期（7/30/永不）自动清理；恢复 / 彻底删除（只清库记录） |
| **从电脑删除**【v2.5.0+】 | 回收站行内危险操作：源文件/漫画源文件夹**真实移入 Windows 回收站**（系统回收站可找回），派生缓存永久清理，DB 记录删除 |
| 批量操作 | 多选移动/收藏/删除/打标签，浮动批量条 |
| 排序 | 最近阅读/书名/导入时间/自定义拖动 × 升降序（图标化下拉收纳）【v2.5.0+】；**排序与方向持久化**（library_sort 键，退书/切架不回落） |
| 状态过滤持久化 | 在读/未读/已读过滤选择持久化（library_status 键），与侧栏快捷 chips 联动跨页面保留 |
| 搜索 | 书名+文件名，**跨书架全库命中**【v2.5.0+】 |
| 书详情 | 编辑标题/作者/简介；封面可自定义更换；统计：进度/阅读时长【v2.5.0+】/格式/大小/书架路径 |
| 密度三档 | 标准/宽松/特大（三格分段图标控件）【v2.5.0+】 |
| 元数据自愈 | 批量修复后一次刷新（不再逐本全量重拉）【v2.5.0+】 |
| 阅读时长统计【v2.5.0+】 | 可见态每分钟落库（reading_sessions），书卡「已读 X 小时」chip + 详情时长行 |

## 3. 阅读器 · 文字书（EPUB/TXT）

| 功能 | 说明 |
|---|---|
| 翻页/滚动双模式 | paginated/scrolled 直切，CFI 进度自动恢复 |
| **开书直达进度**【v2.5.0+】 | 首显直接渲染恢复位置（不再先渲第 1 章再跳，无闪跳）；坏 CFI 自动回退第 1 章 |
| **进度条持久化**【v2.5.0+】 | locations 生成结果存 SQLite（按 字体|字号 档缓存），二次开书秒就绪；生成改 idle 启动不抢首帧 |
| **自定义字体真正生效**【v2.5.0+】 | @font-face 注入 epub iframe，字体就绪才排版；单槽 ttf/otf/woff2 |
| 排版设置 | 字号 80–200%（滑杆拖动只预览、松手才重排【v2.5.0+】）/ 行距 1.5–2.2 / 六字体栈+自定义 / 翻页动画 none·fade·slide × 速度 150–600ms |
| **字号快捷键**【v2.5.0+】 | Ctrl+= / Ctrl+- / Ctrl+0 |
| 版式 | auto（≥1200px 双栏）/单页/双页；EPUB 双页与漫画独立 |
| 划选气泡 | 高亮/收藏/笔记/**复制**【v2.5.0+】（navigator.clipboard） |
| 高亮与笔记 | **原文(text)与笔记(note)分列**【v2.5.0+】，存量自动迁移零丢失；色点标注 |
| 书签 | CFI+章节名定位，Ctrl+B 快加；列表一键跳转 |
| 书内全文搜索 | IndexedDB 缓存索引，结果带章节标题与百分比 |
| 章节预取【v2.5.0+】 | relocated 时预载相邻章 |
| 沉浸模式 | Ctrl+D 锁定全藏；顶/底栏玻璃态唤出 |
| 全局位置页码 | locations 估算（1024 字/页）+ 章内精确页码 |

## 10. 明确不做（防跑偏备忘，源自 v2.5.0 交付文档）

- 不做书城/社区/账号/云同步/防复制/监控
- PDF 只求"能读不卡"（不做 PDF 搜索/大纲/重排/注释导出）
- TTS 朗读、AI 问书/翻译、StarDict 词典、全库备份 zip —— P2 备忘，未排期
- mobi/azw3：纯 Rust 无可用 KF8 解析方案，降级 P2（评估记录：批次 24）
