# BookReading v2.8.0

阅读体验小版本：五件即改即得的使用改进。主题词：**少点几下、少找几眼**。

## 更新内容

- **继续阅读**：书架首页顶部新增"上次在读"快捷卡（封面+进度+一键进入）——每天打开应用的第一本书零查找；✕ 可暂时隐藏
- **目录当前章高亮**：打开目录自动滚到当前章节（accent 左条+加粗），长篇不再从头翻找
- **按作者排序**：书架排序菜单新增"作者"键（收藏页 v2.7 已有）
- **详情页删除**：书籍详情弹窗直接"删除"（软删入回收站），不用再回书架右键
- **布局细节**：进入收藏/回收站时侧栏快捷筛选行不再消失——消灭页面上下跳动

修复 v2.7 引入的目录章节匹配问题（toc 锚点导致高亮失效）。

## 升级说明

无数据库变更；v2.7.0 用户可通过应用内"检查更新"直接升级。
