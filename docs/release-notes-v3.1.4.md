# v3.1.4 · 2026-11-25 · 布局回退修复 + 字体崩溃修复 + 弹窗居中

> 本版本修复 v3.1.2 引入的三个回归问题，是 v3.1.0 的稳定补丁。

## 布局回退根治（v3.1.2 遗留）

- **侧边栏畸形布局修复**：v3.1.2 中误残留的窄窗 CSS 媒体查询（`<719px` 图标栏 / `<899px` 搜索收起 / `<599px` 抽屉）导致品牌标题消失、导航变居中孤立图标、底部按钮变 2×2 拉伸椭圆——本版**全部删除，零残留**
- 侧边栏恢复完整形态：品牌标题区 + 状态标 + 筛选胶囊 + 全文字导航（含副说明）+ 底部四钮纵向全宽排列，**任何窗口宽度锁定不变**

## 字体崩溃修复

- **切换字体白屏修复**：阅读设置中切换正文字体时 `TypeError: Cannot read properties of null (reading 'insertRule')` 导致整页白屏——根因为 epub.js 主题系统在 rendition 销毁后仍被调用；本版加 try-catch 防御 + 路由级 ErrorBoundary 兜底（异常时显示"返回书架"按钮而非白屏）
- 字体切换现在**稳定生效且即时预览**（dev 实测通过）

## 弹窗与抽屉体验

- **弹窗居中修复**：Radix Dialog 的 `transform: translate(-50%,-50%)` 居中方案被其他 CSS transform 干扰导致弹窗整体偏移右下——改用纯 `display: grid; place-items: center` 居中，零 transform 依赖
- **滚动条消失偏移修复**：弹窗/抽屉打开锁定 body 滚动时竖向滚动条消失引起 ~17px 内容右移——加 `scrollbar-gutter: stable` 预留空间
- **抽屉弹跳修复**：开/关右侧抽屉（设置/目录/书签等）时阅读区不再"弹一下"——Drawer 改为始终挂载 + CSS 隐藏/显示，消除挂载瞬间的布局回流

## 开发者

- **dev 数据隔离**：`tauri.dev.conf.json` 独立 identifier（`com.root.bookreading.dev`），以后 `npm run dev:isolated` 启动开发版不再污染正式安装版的书库/设置/WebView2 缓存

## 从 v3.0.1 升级的用户

如果你从 v3.0.1（290MB 版本）直升：字体和排版优化全部包含在内，直接覆盖安装即可，书库数据全保留。
