# v3.2.1 · 2026-11-26 · 启动画面 + 进书加载 + 一批修复

## 启动与进入阅读

- **启动画面**：打开应用先看到「图标 + BookReading」的启动画面，随后书架整体浮入到位（约半秒）；只在冷启动出现，托盘唤起、切换页面不会重播
- **进书加载**：进入一本书时，纸面中央是一枚不断翻动的书页和「正在翻开…」；内容就绪后平滑接上，纸面不再跳动
- 系统开启「减少动态效果」时不播这些动画

## 阅读与书库

- **翻到头有提示**：漫画、PDF、EPUB 翻到首尾再翻，屏幕正中淡入一枚小胶囊——「已是最后一页」/「已是第一页」，按章翻的说「章」；一秒自动消失，按住方向键不会闪
- **修复详情页「移入回收站」实为永久删除**：详情页的删除按钮此前会把书和文件一并直接删掉，现在确实进回收站，可以恢复
- **打开书更稳**：
  - 插图优化副本（.opt.epub）损坏时自动回落原书，下次启动重做
  - 改名成 .epub 的普通文件、截断的压缩包、其它 zip 格式不再能入库
- **插图与封面**：带 EXIF 方向的照片类插图不再躺倒；不同目录的同名插图各用各的尺寸；EPUB 2 封面丢失的几种情形（封面页指向 xhtml、候选类型无法显示、文件名带百分号编码）
- **TXT**：新增识别无 BOM 的 UTF-16；个别坏字节不再让整本变乱码
- **内存与细节**：
  - 每开一本书泄漏的插图 / 字体缓存在关书时释放
  - 夜间 / 墨夜主题下漫画、PDF 折页翻页不再透出新页
  - 更新安装包、导入中断留下的半截文件在启动时自动清理

## 稳定性

- 定向更新了 12 个带已知安全公告的依赖（公告 41 条降到 16 条，其余需要大版本升级，见开发计划）

## 升级说明（此前装在非默认目录的用户请看）

- v3.2.0 起发布者信息变更，而安装器是按「发布者」记住上次安装目录的。所以**装在默认目录以外**的用户（默认目录是 `%LOCALAPPDATA%\bookreading`）从 3.1.9 及更早升级后：新版会装到默认目录，旧目录里的旧版文件和旧快捷方式不会自动更新——从旧快捷方式启动的仍是旧版
  - 想留在原目录：关闭应用后，用安装包指定目录重装一次——「运行」或命令行里执行 `bookreading_3.2.1_x64-setup.exe /D=原目录`（`/D=` 必须是最后一个参数，路径不加引号）
  - 或改用默认目录：把快捷方式指向 `%LOCALAPPDATA%\bookreading\bookreading.exe`，再手动删除旧目录
- 已经是 3.2.0 的用户不受影响，直接更新即可
- 书库、阅读进度、笔记都在 `%APPDATA%\com.root.bookreading`，与安装目录无关，不受影响

## 说明

- 从 3.1.x 直接安装或在线更新即可；从 3.1.9 及更早升级的用户同时获得 v3.2.0 的内容（EPUB 翻页动画四种效果）
- 已知限制：重编码后的插图不保留 ICC 色彩描述（广色域插图会略偏色）；在 3.2.1 之前已经在读、含大量插图的旧书，阅读位置可能偏一两页
