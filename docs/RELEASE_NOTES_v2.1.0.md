# BookReading v2.1.0

发布日期：2026-10-28。聚焦使用顺手度：导入去哪、从哪回来、关不掉的全屏、关窗去哪。

- 导入落点升级：图书 / 漫画 / PDF / 批量 / 拖拽导入，一律进入你当前打开的书架（根视图导入=根书架）
- 阅读页返回：从哪个书架进来的，就回到哪个书架（不再甩回最外层）
- 文件夹漫画源目录移动 / 删除后：打开时明确提示"源文件夹丢失"，一键重新链接到新位置（EPUB / TXT / PDF / CBZ 为复制入库，不受源文件影响）
- F11 全局可用：任意页面按 F11 切换窗口全屏；从阅读页返回书架自动退出全屏（修复"回书架后卡在全屏"）
- 关闭窗口三选：点 ✕ 弹出 退出 / 最小化到托盘 / 取消；最小化后系统托盘常驻图标（单击恢复，右键 显示 / 退出）

升级提示：覆盖安装即可，书库与阅读数据完全保留。
