# v3.1.9 · 2026-11-25 · 设置浮窗 + 书库体检批量处理

## 设置

- **设置改为居中浮窗**：点侧栏「设置」打开浮窗，左侧是分类目录，右侧是对应的配置项，改动即时保存。点遮罩、按 Esc 或点「关闭」退出，底下的书架保持原样
- **八个分区**：外观 / 阅读 / 书库 / 云书架 / 网络与更新 / 快捷键 / 漫画增强 / 关于；小窗口下目录与配置面板自动收窄，切换分区时位置不跳动
- **新增默认阅读设置**：EPUB 的阅读模式、翻页动画、字体与排版，漫画与 PDF 的阅读模式、适配、单双页、阅读方向等，都可以在这里设为新书的默认值。在阅读页里按书单独调过的设置仍然优先

## 书库体检

- **弹窗更大**：操作按钮不用再左右拖动滚动条就能点到
- **批量处理**：失链和重复导入的每一项都可以勾选，也可以「全选」，然后在底栏一次处理，只确认一次
  - 失链 = 从电脑删除（源文件进 Windows 回收站）
  - 重复导入 = 移入书库回收站，可恢复
- **重复导入显示每一份的位置**：所在目录、所在书架、大小和导入时间，方便决定保留哪一份

## 修复

- **同一本书退出后再打开，章内插图变成破损图标**：从 v2.9.0 起就存在的问题——同一次运行里打开的第二本书，图片和内嵌字体的地址替换会整体失败。本版修复，反复打开同一本书插图都正常
- **窗口最右侧多出的一道底色**：v3.1 系列在窗口右缘留了一条颜色略不同的竖条，本版去掉；居中弹窗的位置也随之恢复正中
- **圆角弹窗的滚动条不再压进圆角**

## 说明

- 翻页动画的行为与 v3.1.8 相同，新的翻页效果会在 3.2 提供
- 从 3.1.x 直接安装或在线更新即可，书库与阅读进度不受影响
