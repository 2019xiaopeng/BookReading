# 开发计划 v3.0.1（wenku8 云书架 · 验收驱动版）

> 2026-11-20 一日完成：v3.0 功能开发 + 七轮实机验收打磨，直接以 3.0.1 号段发布。
> 版本语义：3.0.1 = 3.0 全部功能（批次 1-12）+ 终批收尾（批次 13），跳过 3.0.0 号段。

## 一、功能主体（批次 1-6）

- Rust wenku8 模块：appver 动态签名（HMAC-SHA256 + magic，60s 窗口，实测验证）、中继客户端（专用线程 + no_proxy + 30s 超时）、会话 cookie 持久化 + errcode 4 自动重登、并发 4 下载拼装 TXT → 现有导入管线入库
- 云书架页：登录卡 / 书卡懒取书名 / 拉取进度事件 / 已入库去重（books.wenku8_aid + wenku8_last_cid 列，书架接口 DB join 免 N+1）/ 有新章懒比对 / 详情对话框（目录 wenku8_catalog / 简介 / 目标书架记忆 wenku8.dest_shelf）/ 网页版入口 / 拉取单飞锁
- 拉取元数据落地：简介→description；标签→本地标签系统（幂等挂接）

## 三、v3.1 候选（累计微调意愿存档）

- 在线流式阅读（Wenku8_Flutter 同款：云端书直接在线读 + 章节级离线缓存；已论证 v3.0 选择整本拉取的理由——网络可靠性与本地阅读器优势）
- 增量更新替换（新章追加并迁移阅读进度，替代现在的「有新章」徽标+手动重拉）
- 云书架搜索（当前为本地过滤书名/作者；可加云端搜索 action=search 接入全站检索）
- 试读模式（拉取前 N 章尝鲜再决定整本）
- 云书架写操作（加书/删书/签到）
- 拉取失败单章重试；详情对话框封面独立重试
- 直连端点降级（app.wenku8.com/api.php，appver=1.21 明文——relay 关停时启用；android.php 已废弃）
- 历史遗留 P2：极品家丁装饰 logo 错配、mobi/azw3（libmobi FFI）、StarDict 词典、阅读报告图、背景图多张轮换、TTS 二期
