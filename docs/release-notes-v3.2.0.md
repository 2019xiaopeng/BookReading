# v3.2.0 · 2026-11-26 · EPUB 翻页动画全新实现

## 翻页

- **四种翻页效果**：在「设置 → 阅读 → 翻页动画」或阅读页的设置抽屉里选择
  - 平移：新页从一侧推进，旧页同步退出，两页首尾相接
  - 覆盖：新页滑入压住停在原处的旧页，前缘带一道阴影
  - 渐隐：新旧两页交叉淡化
  - 纸页翻动：旧页自边缘掀起、折痕扫过整页，新页从掀开处露出
- **翻页时看到的就是真实页面**：主题、字体、高亮、插图、页码都原样跟随
- **跨章不再闪白**：翻到下一章时旧页停住，等新章排好版再翻过去；选「无」同样不再白屏
- 速度仍可在 150–600ms 之间调节，每种效果按同一档位缩放

## 连按与手感

- 连续按键每次恰好翻一页，不会丢步或卡住；按得快时中间几页直接跳过动画，最后一页才播
- 动画进行中继续点击、滚轮或按键，立刻接着翻下一页
- 竖排书只翻页、不播横向动画；系统开启「减少动态效果」时不播动画

## 其它

- **发布者与作者信息**：安装器与系统「应用和功能」里显示的发布者改为 qcb，程序描述不再是模板占位文字
- 从 3.1.8 及更早版本升级的用户同时获得 v3.1.9 的内容：设置改为居中浮窗、默认阅读设置、书库体检批量处理，以及同一本书再次打开时章内插图丢失的修复

## 升级说明（此前装在非默认目录的用户请看）

- 本版起发布者信息变更，而安装器是按「发布者」记住上次安装目录的。所以**装在默认目录以外**的用户（默认目录是 `%LOCALAPPDATA%\bookreading`）升级后：新版会装到默认目录，旧目录里的旧版文件和旧快捷方式不会自动更新——从旧快捷方式启动的仍是旧版
  - 想留在原目录：关闭应用后，用安装包指定目录重装一次——「运行」或命令行里执行 `bookreading_3.2.0_x64-setup.exe /D=原目录`（`/D=` 必须是最后一个参数，路径不加引号）
  - 或改用默认目录：把快捷方式指向 `%LOCALAPPDATA%\bookreading\bookreading.exe`，再手动删除旧目录
- 装在默认目录的用户不受影响
- 书库、阅读进度、笔记都在 `%APPDATA%\com.root.bookreading`，与安装目录无关，不受影响
## 说明

- 需要 WebView2 运行时 111 及以上（Windows 10 / 11 的常青版一般已满足）；不满足时自动退回原来的「先画完再微幅滑入」
- 从 3.1.x 直接安装或在线更新即可，书库与阅读进度不受影响
- 本版不含：鼠标按住拖动翻页、前端热更新（计划在 3.3）
