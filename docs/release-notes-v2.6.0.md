# BookReading v2.6.0

库管理大升级 + 插图性能根治 + 阅读器排版与朗读。主题词：**书库自己会体检，插图多的大部头也不卡，排版细到段距首行缩进**。

## 性能：插图多的 EPUB

- **导入时自动生成"阅读优化副本"**：书内大插图（长边 >1800px）缩放到 1520px（纸面 2 倍 DPR 上限），翻倍变小的才替换——原书文件保留不动，阅读器自动优先打开优化版
- 插图注入宽高属性（翻到图页不再跳版）+ 懒加载（滚到才解码）；存量书首次启动后台自动补生成优化副本（不卡界面，有进度）
- 实测：301MB / 12 张 2800px 大插图的压力书——导入即生成优化副本（插图全部缩至 ≤1520px、注入宽高、懒加载），开书直接走优化副本；同体量书的 locations 后台生成不再被插图拖垮

## 书库管理

- **右键书卡 = ⋯ 菜单**：右键与右上角三个点完全同款
- **⋯ 菜单直接「从电脑删除」**：源文件/漫画源文件夹移入 Windows 回收站（可从系统回收站找回），不必再绕回收站页
- **打开所在位置**：⋯ 菜单与书籍详情一键在资源管理器中定位源文件/源目录
- **书库体检**：设置里一键检查三类问题——重复导入、源目录被移动/改名（可直接「重新链接」）、悬空封面——逐项给出处理动作
- **滚动位置记忆**：从书里退回来，书架停在你刚才看到的位置；收藏页记住上次所在标签页

## 阅读器

- **排版细项**：字重三档、字间距、段间距、首行缩进、页边距、两端对齐——全部实时生效
- **排版按书记住**：字号/行距/排版细项可在书内单独设定（epuset 书级覆盖，全局作默认）
- **朗读（一期）**：顶栏一键朗读当前章（系统语音），语速可调；翻章自动停
- **背景纱浓度**：全局背景图的纸面纱浓度 60–95% 可调
- 排序与方向、在读/未读过滤状态持久化（退出重开不再回落默认）
- 修复一个 v2.5.0 的隐性缺陷：自定义字体注入此前未真正生效（epubjs hook 挂错管线），本版修正并实测

## 升级说明

- 首次启动会为插图多的存量书后台生成优化副本（进度在设置→书库体检旁提示；只读不改原文件）
- 数据库无结构变更；升级前仍建议备份 `%APPDATA%\com.root.bookreading`
