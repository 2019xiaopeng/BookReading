# 2026-10-27 批次8 · 层级书架与回收站 — 变更记录

## 数据层
- shelves 表（id/name/parent_id/sort_order）+ books.shelf_id/sort_order/deleted_at；幂等迁移：旧 group_name → 根级书架。
- shelves.rs 13 命令：书架 CRUD/防环移动/级联删（书挂父级）/排序；书批量移动/排序/软删/恢复/硬删（purge 仅删库内文件，文件夹漫画不动源）/list_trash/保留期（7/30/永不，默认 30）；启动自动清过期回收站。
- 全部查询过滤 deleted_at IS NULL（含收藏）。

## 前端
- 书库层级视图（?shelf=id）：书架卡+书卡混排、面包屑（可点击+拖放目标）、右键重命名/移动/删书架；自定义排序档拖拽换序（书/书架各自落库）。
- 批量选择模式：浮动批量条（移动到书架/收藏/删除入回收站/全选）。
- 回收站视图（?trash=1）：行式列表（封面/删除时间/剩余天数）、恢复/彻底删除/清空、保留期下拉。
- 侧栏：书架树（缩进层级）+ 回收站入口。
