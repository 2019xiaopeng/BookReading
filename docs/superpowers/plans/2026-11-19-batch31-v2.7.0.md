## 方法论沉淀
- reqwest::blocking 与 Tauri async 命令线程不兼容（死锁在 build）——任何阻塞 HTTP 必须专用 std::thread
- epubjs `rendition.hooks.content`（Contents 对象）vs `book.spine.hooks.content`（裸 document）签名差异是 v2.5/v2.6 两个静默 bug 的同根
- 验收矩阵 + 真实大书（169MB 多媒体 EPUB）是抓管线级缺陷的最有效手段
