## 1. 导入漫画后不自动刷新

根因：单本"导入漫画"按钮直接调 importImageFolder（src/pages/LibraryPage.tsx），不经过 importRunner，而 BOOKS_CHANGED_EVENT 只在 runImportBatch 结束时广播；LibraryPage 侧订阅（批次12b 已有）收不到事件。

修法：LibraryPage.onImportImages 改调 importRunner 新入口 importSingle(dir)（走同一串行队列：查重交互 + BOOKS_CHANGED_EVENT 广播）；"未找到图片"时父目录批量导入引导保留——importSingle 把失败原因（error 字符串）返回调用方，原 showConfirm 兜底链路不变。验收：导入一本 → 不手动刷新书卡即出现。

## 6. 迁移后清理旧库（追加）

- Rust storage.rs：migrate_library_root 返回结构 MigrateResult { moved_bytes, old_library, old_db }（invoke.ts 同步类型），并在迁移成功后把旧根写入 settings 键 last_migrated_from（bootstrap db / 新根 db / 迁移当时旧 db 三处，会话内立即清理也可校验）。
- 新命令 remove_old_library(oldLibrary, oldDb)：安全校验（路径非空、绝对、不等于当前 library_root、不与当前书库嵌套、且等于当前 db 记录的 last_migrated_from）→ 删旧 library 目录与旧 db（含 -wal/-shm；bootstrap db 永不动；旧 db 在旧目录内时随目录一并删除）→ 清除标记（防二次调用）。
- SettingsDialog.onMigrate：成功后 showConfirm"是否删除旧位置的库文件以释放空间？\n{oldLibrary}"→ 是=removeOldLibrary（结果/失败 alert），否=alert 附"旧文件保留于 …，可稍后手动删除"。
