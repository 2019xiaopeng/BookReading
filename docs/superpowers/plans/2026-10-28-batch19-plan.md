# 2026-10-28 批次19 · 全局 F11 + 关闭三选 + 系统托盘 — 变更记录

三件：F11 全屏上提全局 / 返回书架自动退全屏 / 窗口 ✕ 三选（最小化到托盘 / 退出 / 取消）+ 系统托盘常驻。唯一依赖变动是 tauri crate 的 `tray-icon` feature（非新依赖，Cargo.lock 中 tray-icon 0.23.1 / muda 0.19.1 原本就在）。门禁：npm run build + npm run test（129 绿）+ cargo check/test（89 绿）。

## 1. 全局 F11

现状：F11 处理器只挂 ReaderPage 的 window keydown，回书架后按 F11 无效、全屏卡死（只能 Alt+F4）。

修法：

- `src/App.tsx`：useEffect 挂 window keydown——`F11 → e.preventDefault() → getCurrentWindow().setFullscreen(!(await isFullscreen()))`，失败 logFrontend。不判输入焦点（浏览器惯例，保持原 ReaderPage 行为）。
- `src/pages/ReaderPage.tsx`：原 F11 分支删除（原位置留一行注释），避免与 App 级监听双触发（两个 window 级监听都会收到 keydown，preventDefault 挡不住；双触发 = 两次并发 toggle，可能同读同写互相抵消/误入全屏）。

静态推演：书架页 F11 → 进/出全屏（新增能力）；阅读页 F11 → 单次 toggle（行为不变）；输入框焦点 F11 → 仍生效（与原一致）。epub 章节内部 iframe 持焦点时主文档收不到 keydown——原有局限，未变。

## 2. 返回书架退出全屏

修法：`src/pages/ReaderPage.tsx` 返回按钮抽成 `backToLibrary()`——先 fire-and-forget `isFullscreen() → setFullscreen(false)`（catch 记日志），随即 `navigate(?shelf=N 或 /)`，不等 setFullscreen 落地。沉浸锁定态 Esc 只解锁 chrome，不动窗口全屏——两层独立语义保持不变。

静态推演：全屏读书 → 返回 → 窗口回非全屏 + 落原书架；非全屏 → 无额外调用；setFullscreen 失败（理论不发生）→ 照常导航 + 日志留痕。

## 3. 关闭三选

- Rust（`src-tauri/src/lib.rs`）：Builder 挂 `on_window_event`——`WindowEvent::CloseRequested { api, .. }`（枚举 non_exhaustive 必须带 `..`）→ `api.prevent_close()` + `window.app_handle().emit("wr:close-requested", ())`（`use tauri::{Emitter, Manager, WindowEvent}`）。新命令 `#[tauri::command] fn quit_app(app: AppHandle) { app.exit(0) }` 注册进 generate_handler——`AppHandle::exit` 走 ExitRequested 流程，不触发 CloseRequested，不进拦截循环。
- 前端（`src/App.tsx`）：`listen("wr:close-requested")`（core:default 自带 core:event:default，无需新权限）→ `showChoice`（批次16 三键对话框）：主钮"退出"= `invoke("quit_app")`，次钮"最小化到托盘"= `getCurrentWindow().hide()`（capabilities/default.json 补 `core:window:allow-hide`），取消（Esc / 点遮罩）= 不动。卸载守卫 disposed 标记防 StrictMode 竞态。
- 关机取舍：tao 0.35 不处理 `WM_QUERYENDSESSION`，系统关机不产生 CloseRequested，prevent_close 不会阻止关机；NSIS 升级安装器对运行中进程 taskkill，同样绕过。代码内留 shortcut 注释说明。

## 4. 系统托盘

- `src-tauri/Cargo.toml`：`tauri = { version = "2", features = ["tray-icon"] }`（crate feature，非新依赖）。
- `src-tauri/src/lib.rs` setup 尾部（init_db 后）：
  - `Menu::with_items` + `MenuItem::with_id(app, "show"/"quit", "显示主窗口"/"退出", true, None::<&str>)`。
  - `TrayIconBuilder::with_id("main").tooltip("BookReading").menu(&menu).show_menu_on_left_click(false)`（tray-icon 默认左键弹菜单，关掉让位给单击恢复）`.icon(app.default_window_icon().cloned())`（bundle 图标；None 时跳过不硬失败）。
  - `on_menu_event`：show → `get_webview_window("main").show()+set_focus()`；quit → `app.exit(0)`。
  - `on_tray_icon_event`：`TrayIconEvent::Click { Left, Up }` → 同 show。
  - build 返回值即弃——tauri 2.11 `register()` 会 clone 进 manager 的 resources_table，托盘不随 setup 闭包结束消失。
- 托盘常驻：窗口 hide 后 Windows 任务栏图标消失（默认行为，符合"最小化到托盘"预期），托盘图标留存；无需前端 capability（Rust 侧自足）。
- README：快捷键表 F11 行改"全局"场景 + 功能总览补托盘行为一行。
