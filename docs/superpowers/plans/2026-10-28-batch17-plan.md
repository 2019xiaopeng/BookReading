## 1. 书架卡拖到侧栏“回收站” = 删除书架

现状：canDropOn 只放行书卡（mode=trash → book），书架卡拖到回收站无响应。批次15 只接了书卡软删链路。

修法（src/pages/LibraryPage.tsx）：

- canDropOn 书架分支头部放行 `mode === "trash"`（回收站视图内同书卡分支再挡一层 `!trashView`，防自删困惑）。
- onUp 书架分支分流：`drop === "trash"` → 新增 dropOnTrashShelf(id)，否则原 dropOnShelf。
- dropOnTrashShelf：showConfirm 文案“删除书架《X》？其内书籍将移到上一级，子书架一并删除（与右键删除一致）。”→ deleteShelf(id) → refresh + BOOKS_CHANGED_EVENT 广播（跨窗口同步）。删的是当前书架/祖先时回根由既有 effect（shelves 更新后 currentShelfId 悬空 → navigate("/")）兜底，与右键删除一致。

静态推演：架→回收站（非回收站视图）确认后删除并广播；书→回收站原链路不变；回收站视图内两者皆禁（`!trashView` 守卫 + 回收站网格无书架卡拖拽源）；架→架/面包屑/new-shelf 虚线卡行为不变（new-shelf 仍只对书卡开放）。

## 2. PDF 位置记忆（连续滚动模式落位）

- 离开滚动模式复位守卫：再次进入时按当前页重新锚定（保留旧有再入行为）。
- shortcut：恢复页之前有个别页尺寸获取失败时等不到就绪、停在顶部（与修复前一致），可手动滚动定位。

退出持久化路径核验（已存在，未改动）：onRelocated → ReaderPage.handleImageRelocated 对 pdf 格式 upsert `pdf:N`（1500ms 防抖），unmount/pagehide flush 直写 lastCfiRef。

静态推演：分页模式重开 → 恢复页 N 直接渲染位图；连续滚动重开 → N=0 立即落位，N>0 等全量 dims 后 scrollTop=offsetTop(N)，IntersectionObserver 锚定不回跳（整屏级大跳不参与续读判定）。

## 3. 漫画翻页卡顿（批次16 回归：±4 全量并发解码 + 翻页叠加淡入）

根因：批次16 预载窗口 ±4，翻页一次触发约 7-9 张 readImagePage + `await decode()` 并发；解码完成回调同帧扎堆回主线程，翻页动画被拖。且 weread.css `.wr-image-fit img` 的 120ms 淡入作用于每次 img 挂载——翻页换 spread 时页码 key 重建 img 元素，淡入与 slide 转场叠加（旧页快照层同理，出场中还在从 0 淡入）。

修法（src/reader/image/ImageReader.tsx + src/ui/weread.css）：

- a) 当前 spread（webtoon=锚点页）仍立即 ensureLoaded，内部保持 `await decode()` 完成才入缓存/换页（切换即显、批次16“消半载入闪白”不回退）。
- b) 其余邻页按 |页号-当前页| 距离排序，逐张 setTimeout(order×16ms)（一帧一张）启动——同帧解码量≤1；每次翻页重建队列（effect cleanup 清旧定时器），新当前页恒为立即档。
- c) 预载窗口 ±4 → ±3（2 与 4 折中，减少同时解码量与常驻内存）。
- d) 淡入只作用于“占位→成像”：swap effect 判定相邻翻页（|ΔspreadIndex|=1）→ setReveal(false)，img 挂 wr-img-instant 类（CSS animation:none）；初始载入/远跳（占位→成像）保留 120ms 淡入。旧页快照层（--out）img 常驻 instant。webtoon 条带 img 不变（本就只有占位→成像一种路径）。
- e) PagesPanel THUMB_LIMIT=48、PdfReader 位图窗口 ±3 均保留不动。

静态推演：翻页=当前 spread 立即解码 + 邻页隔帧排队；快速连翻时队列重建、已载页缓存命中零开销；跳页远端目标按占位→成像淡入。

## 4. 小说 slide 翻页空窗（两段式中间清空闪白）

现状（ReaderPage.animateTurn slide 分支）：出场动画 await wait(outMs) → 完成后才 await run()（display 新 CFI）→ 空窗=出场时长+display 耗时，串行叠加。epub.js 单 iframe 无法保留旧 DOM 双缓冲（html2canvas 又禁新增依赖）。

修法（src/pages/ReaderPage.tsx）：采纳压缩空窗方案——出场动画与 display 并行：

- 时序：t0 同时启动出场 transform 与 run()（display 异步渲染，旧页滑出的同时后台已在画新页）；await Promise.all([wait(outMs), displaying])；两者齐后立即入场。空窗从“出场时长+display 耗时”缩到 max(0, display-出场)——display 快于出场时为 0。
- 出场段上限收紧：outMs = min(40%×turnSpeedMs, 120ms)（原 150×k 固定比例）；入场 240×k 与兜底 260×k 不变。
- 快速连翻：turningRef 已有守卫（动画进行中直接瞬时跳页不排队），并行化后 finally 恒复位，无卡死路径。

静态推演三档速度（150/260/600ms）：出场 60/104/120ms，入场 139/240/554ms；连翻期间 turningRef 分支直跳，动画状态机无重入。
