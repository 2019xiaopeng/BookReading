# 批次26：从电脑删除（真实文件删除）+ 发布收尾

用户需求：原"彻底删除"只清书库记录（文件夹漫画原地引用不动源目录），需要能**真实删除**所选书籍/漫画的电脑文件。

## 实现
- Rust：新命令 `delete_books_from_disk(book_ids) -> u32`（shelves.rs）——库内副本（EPUB/TXT/PDF/CBZ 的 library/books/{id}.*）或文件夹漫画源目录（绝对路径）经 **trash crate 5.x 移入 Windows 回收站**（系统回收站可找回）；封面/缩略档等派生缓存永久清理（缩略双扩展名兜底）；trash 失败即该本中止报错，绝不静默永久删除；随后 purge 掉 DB 行
- 前端：回收站行新增「从电脑删除」危险钮（恢复/彻底删除/从电脑删除三钮），确认对话框明示"源文件（漫画为整个源文件夹）移入 Windows 回收站"
- 验证（实机）：测试书走完 软删→回收站行→点钮→确认→源文件从磁盘消失（进系统回收站）→DB 行清零 ✅

## 设计取舍
- 入口只放回收站页（删除→回收站→真删，两步防误删）；书卡菜单保持"删除"单入口
- 无 cargo 单测：trash 调真实 Shell API 且会污染开发机回收站；路径分派逻辑由既有 purge 测试覆盖
