# 2026-10-28 批次18 · 测试期小优化三件套 — 变更记录

三项：导入落到当前书架 / 阅读页返回原书架 / 文件夹漫画丢失源重链接。无新依赖、无行为回退（state 缺失时全部回退旧路径）。门禁：npm run build + npm run test（129 绿）+ cargo check/test（89 绿，含 4 个新 relink 测试）。

## 1. 导入落到当前书架

现状：导入的书全部落根（shelf_id NULL）。目标：导入到用户当前打开的书架。

修法：

- `src/library/importRunner.ts`：
  - `importOne` 由返回 void 改为返回新书的 `book.id`（`importBook` / `importImageFolder` 均返回完整 `Book`，无需改 Rust）。
  - 新增 `ImportOpts = { force?: boolean; targetShelfId?: number | null }`；`runImports` / `importSingle` 接受并透传；`runImportBatch(paths, force, targetShelfId)` 收集成功项 `importedIds`，循环结束后 `targetShelfId != null && importedIds.length > 0` 时一次 `moveBooksToShelf(importedIds, targetShelfId)`（try/catch 记日志，不吞导入结果；放在 BOOKS_CHANGED_EVENT 广播前，刷新看到的就是最终 shelf_id）。`showSummary` 的"导入全部副本"重入也携带 targetShelfId。
- `src/pages/LibraryPage.tsx`：`onImport` / `onImportImages`（importSingle 与批量引导 runImports）/ `onBatchImportImages` 四个调用点全部传 `{ targetShelfId: currentShelfId }`。书架空白处右键菜单的"导入图书/导入漫画/批量导入漫画"与侧栏按钮共用这三个 handler——handler 层接入即自动覆盖（核对无独立处理函数）。
- `src/ui/AppShell.tsx`：OS 拖拽导入入口按 URL 计算 `dropShelfId`（与 LibraryPage.currentShelfId 同口径：active=library 且非回收站视图且 ?shelf= 可解析），`runImports(paths, { targetShelfId: dropShelfId })`；effect 依赖加 `dropShelfId`。

静态推演：根视图按钮/右键导入→根（currentShelfId=null，不调 move，与旧行为一致）；子书架视图按钮/右键导入→该子书架；子书架视图 OS 拖拽导入→该子书架；回收站视图右键导入→不可达（网格容器只在非回收站分支渲染，右键菜单不存在）；回收站视图侧栏导入按钮→可达但 currentShelfId=null→落根（现状如此，未加新守卫）；收藏页拖拽导入→根。

## 2. 阅读页返回原书架

现状：ReaderPage"返回书库"固定 `navigate("/")`。

修法：

- `src/pages/LibraryPage.tsx`：新增 `openBook(id)` = `navigate(`/read/${id}`, { state: { fromShelf: currentShelfId } })`，书卡 click 与 Enter 两处改用它（react-router-dom location state，随 navigate 携带，不占 URL）。
- `src/pages/ReaderPage.tsx`：`fromShelf = location.state?.fromShelf`；返回按钮 `navigate(typeof fromShelf === "number" ? `/?shelf=${fromShelf}` : "/")`。

静态推演：子书架读书→返回→`/?shelf=N` 仍在子书架且该书可见；根视图读书→state.fromShelf=null→回根（与旧一致）；收藏页/刷新后（state 丢失）→回根，原行为不变；阅读中书架被删→返回后 LibraryPage 既有 effect（currentShelfId 悬空）自动回根。任务书要求的"收藏页返回回收藏页"未实现（现状本就回根，按"state 缺失回原行为"口径保持）。

## 3. 文件夹漫画丢失源的重链接

现状：源目录移动/删除后打开报错，无恢复路径。

修法：

- Rust（`src-tauri/src/commands/images.rs` + `lib.rs` 注册 `relink_image_book`）：
  - 命令 `relink_image_book(book_id, new_path)` → 内部 `relink_image_folder(conn, ...)`（无 AppHandle，可测）：校验书存在且 format='images'；CBZ（库内相对路径）拒绝"无需重链接"；new_path 为存在目录且绝对；`folder_image_files`（复用导入的过滤+自然序）≥1 图；规范化（`\`→`/`、小写、去尾斜杠，与前端 normPath 同口径）不与其它在库 images 书 library_path 重复（fetch_books 忽略回收站，与导入查重一致）→ `UPDATE books SET library_path=绝对路径, page_count=新页数` → 返回更新后 Book。
  - 测试 4 个：非 images+CBZ+缺书拒绝 / 目录不存在+空目录拒绝 / 成功更新 path+page_count / 路径撞车拒绝（反斜杠+大小写差异也撞）。
- 前端：
  - `src/reader/image/api.ts`：`relinkImageBook(bookId, newPath)`。
  - `src/reader/image/ImageReader.tsx`：装载失败错误浮层（list_image_pages 失败路径）加"源文件夹丢失？重新链接…"按钮（仅 folder 漫画：format=images 且 library_path 非 .cbz）→ `open({ directory: true })` → relink → 成功后广播 BOOKS_CHANGED_EVENT 并 `reloadKey+1` 触发装载 effect 重跑（book.id 不变，靠新 dep 重载）；失败 showAlert（dialog.tsx 体系）。EPUB/PDF/CBZ 均为库内文件，不走此路径（按钮不显示）。

静态推演：移走源目录→打开→错误浮层→选新位置（含图）→library_path 改写→阅读器自动重载回第 1 页（进度 CFI 由 getReadingState 恢复，img:N 超界由 clampPage 钳回）；新位置被另一本占用→后端拒绝并提示；空目录→"未找到图片"。
