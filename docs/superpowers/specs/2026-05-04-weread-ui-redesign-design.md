# 微信读书风 UI 重设计（书架/收藏/阅读器）设计文档

日期：2026-05-04

## 1. 目标与范围

### 1.1 目标

- 将现有桌面端阅读器整体 UI 收敛到“微信读书风”：纸感、克制、信息层级清晰、阅读沉浸
- 完整覆盖现有功能面：书架、收藏页、阅读器侧栏（目录/书签/标注/收藏句子/搜索/设置）、阅读交互（选中文本、跳转定位、沉浸、进度与翻页）
- 提升可用性与可观测性：
  - 解决排版溢出与布局不一致
  - 关键异常可定位（前端日志已存在）

### 1.2 不做（本轮不改）

- 不新增账号体系/云同步/听书
- 不改变数据模型与后端接口语义（除非为 UI 必要的轻量字段补齐）
- 不追求 1:1 复刻微信读书所有细节（目标是“风格一致 + 交互合理”）

## 2. 设计基线：形态与信息架构

### 2.1 基线形态（用户确认）

- 桌面布局为主
- 关键控件（主题/字号/行距/进度等）采用移动端“抽屉式”面板交互

### 2.2 顶层信息架构

- 全局 Shell（跨页面一致）
  - 左侧导航栏（固定宽度）
    - 书架
    - 收藏
    - 阅读中（仅阅读页：目录/书签/标注/收藏句子/搜索/设置入口）
    - 底部：导入入口、阅读设置入口、主题快捷切换
  - 顶部工具条（跨页面一致）
    - 全局搜索（书名/作者/收藏句子/笔记）
    - 右侧：导入、收藏入口、状态/提示区
  - 主内容区（随页面变化）

### 2.3 页面级结构

- 书架
  - 卡片网格为主，支持更密的列表态（可选）
  - 卡片信息：封面、标题、作者、阅读进度、最近阅读
  - 主要动作：继续阅读
  - 次要动作：收藏/取消收藏、删除（弱化但可达）
- 收藏页
  - Tab：收藏书籍 / 收藏句子
  - 收藏句子：搜索 + 书籍筛选 + 跳转定位 + 删除
- 阅读页
  - 中央纸张阅读区（宽度收敛，避免全屏溢出）
  - 右侧抽屉：目录 / 书签 / 标注 / 收藏句子 / 搜索 / 设置
  - 底部进度条常驻，顶部工具条可在沉浸模式隐藏

## 3. 视觉系统（微信读书风 DNA）

### 3.1 主题与色彩

- 三主题一致：light / sepia / dark
- 纸感与层次：
  - 背景为“环境光”底色
  - 内容承载为“纸张”层
  - 控件为“轻描边 + 低对比阴影”
- 主色（强调）使用克制的绿系，仅用于关键动作与状态提示

### 3.2 排版与阅读体验

- UI 字体：系统 sans（苹方/微软雅黑优先）
- 正文更偏衬线观感（可保持 epub.js 内部字体，但通过主题注入统一边距/行距/断行规则）
- 关键排版约束（必须）
  - 阅读内容区域固定最大宽度（如 680–820px 范围）
  - `word-break/overflow-wrap` 保证长句/英文/URL 不溢出
  - 图片/表格 `max-width: 100%`，避免横向滚动

### 3.3 组件语法（统一“骨相”）

- Button：primary/secondary/ghost/danger（主色仅用于 primary）
- Card：纸张质感，轻阴影、圆角克制
- Tabs：浅背景胶囊，选中态更像“纸面凸起”
- Empty/Error：统一空态/错误态与轻量引导

## 4. 交互设计（关键链路）

### 4.1 阅读主流程

- 书架卡片点击“继续阅读”进入阅读页
- 阅读页默认显示纸张阅读区
- 右侧抽屉默认收起，通过顶部/快捷键打开

### 4.2 抽屉式面板（阅读页）

- 入口：
  - 顶部工具条按钮（目录/搜索/设置等）
  - 快捷键（Ctrl+F 打开搜索并聚焦）
- 面板内容：
  - 目录：章节列表（支持跳转）
  - 书签：添加、列表、删除、跳转
  - 标注：列表、删除、跳转
  - 收藏句子：列表、删除、跳转
  - 搜索：结果列表、跳转
  - 设置：主题/字号/行距/翻页动画

### 4.3 选中文本的“微信读书风”操作条

- 取代 confirm/prompt 弹窗链路，改为轻量浮层（原位、不打断阅读节奏）：
  - 高亮
  - 收藏
  - 复制
  - 笔记（打开抽屉中的笔记编辑视图）

### 4.4 沉浸模式

- 进入沉浸：
  - 隐藏顶部工具条与侧栏
  - 仅保留轻量进度与唤出手势
- 退出沉浸：
  - Esc 或双击/快捷键
