# 批量多选导入 EPUB 设计文档

日期：2026-05-04

## 1. 目标与范围

### 1.1 目标

- 书库页支持一次选择多个 EPUB 文件导入
- 按顺序导入，单个失败不影响后续
- 完成后仅刷新书架，无额外提示

### 1.2 范围

- 仅修改前端书库页导入流程
- 不新增后端命令或数据库变更
- 不支持目录导入
- 不新增进度或结果列表 UI

## 2. 用户流程

1. 点击“导入 EPUB”
2. 文件选择器支持多选 EPUB
3. 取消选择则不进行任何操作
4. 选择后按顺序导入，每个导入失败仅记录日志
5. 全部完成后刷新书架一次

## 3. 技术方案

### 3.1 入口改动

- 使用 `@tauri-apps/plugin-dialog` 的 `open({ multiple: true })`
- 统一返回值为路径数组，依次调用 `importBook`

### 3.2 错误处理

- 每个文件导入使用 `try/catch`
- 失败时调用 `logFrontend` 记录文件路径与错误信息
- 不中断剩余导入

### 3.3 数据流

- 选择文件 → 前端顺序调用 `importBook` → 后端复制/解析 → 写入数据库 → 前端刷新列表

## 4. 测试与验收

- 可一次选择多个 EPUB 并全部导入
- 混合有效/无效文件时，导入继续进行
- 取消选择不会触发任何导入
- 导入完成后书架列表更新

## 5. 非目标

- 文件夹导入
- 导入进度条或结果提示
- 并行导入或后端批量接口
