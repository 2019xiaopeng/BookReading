# 阅读页交互与版式对齐（temp 原型）设计

## 背景与问题

当前阅读页存在以下问题：

1. 阅读舞台左右留白过大，“左右没占满”，双栏时舞台宽度与 spread 逻辑不一致导致排版异常。
2. 沉浸模式在阅读过程中频繁误切换（尤其在点击/双击/翻页过程中）。
3. 正文无法稳定选中，导致标注/收藏无法触发（点击翻页热区/遮罩拦截了事件）。
4. 主题/护眼色切换出现“像从头翻到当前位置”的观感（推测由 reader/rendition 重建与重复 display 引起）。

本设计目标是在不引入新依赖的前提下，将阅读页交互收敛为可预期规则，并尽可能靠齐 temp 原型的体验。

## 目标与非目标

### 目标

- 阅读舞台宽度策略改为“自适应填满（保留小边距）”，减少大屏留白。
- 点击翻页改为“仅左右边距可点”，正文区域不拦截事件，恢复选中标注/收藏。
- 沉浸模式切换入口收敛为“按钮/快捷键/HUD”，禁用双击任意处切换，消除误触。
- 主题/护眼/字体/版式变化时不重建 reader，不触发重复 display，避免“回翻”观感。
- 双栏（单/双/自动）行为稳定：spread 计算与舞台尺寸保持一致。

### 非目标

- 不在本轮引入 Playwright 等端到端测试框架。
- 不在本轮引入复杂的 iframe 内注入键盘事件；沉浸模式下翻页以 HUD/边距点击为主。

## 交互规范

### 阅读舞台（Paper Stage）

- 舞台容器始终占满可用高度。
- 舞台宽度：`width: 100%`，仅保留固定左右边距（例如 18px），不再以固定 maxWidth 作为主要约束。
- 单栏/双栏只影响 epubjs spread 与内部排版，不通过缩窄舞台宽度实现。

### 点击翻页热区

- 仅在阅读舞台内部放置左右热区：
  - 左热区：约 18–22% 宽度
  - 右热区：约 18–22% 宽度
- 中间正文区域不拦截事件，保证 iframe 内可选中、可拖拽。
- 当选中文本操作条显示时：
  - 保持热区仍可点，但操作条所在区域优先响应操作条按钮；
  - 允许在实现中选择“操作条显示时暂时禁用热区”以进一步减少误触。

### 沉浸模式

- 切换入口仅保留：
  - 顶部“沉浸”按钮进入
  - `Ctrl + D` 切换
  - 沉浸 HUD “退出沉浸”按钮退出
- 禁用双击任意处切换沉浸。
- 沉浸 HUD：
  - 鼠标移动到顶部 56px 区域显示
  - 2.5s 无操作自动隐藏
  - 提供：退出沉浸、目录、上一页/下一页、进度百分比

## Reader 生命周期与状态管理

### 创建/销毁

- 仅在以下变化时创建/销毁 reader：
  - `bookId` 变化
  - URL `cfi` 参数变化（可选：仅首次进入读取一次）
- 销毁时清理：rendition、事件监听、定时器。

### 更新（不重建）

- 以下变更只调用 controller 方法，不重建 reader，不重新 `display()`：
  - `theme`：`setTheme`
  - `fontSizePercent`：`setFontSizePercent`
  - `layoutMode`：`setSpreadMode`
- `layoutMode=auto` 时监听窗口尺寸变化：
  - 重新计算 spread
  - 调用 `setSpreadMode` + `resize`（如可用）
- 禁止在这些更新中触发“恢复阅读进度”的逻辑，避免“回翻”。

## 双栏（单/双/自动）

- `layoutMode`：
  - `single` → spread `none`
  - `double` → spread `both`
  - `auto` → 根据舞台实际可用宽度判定 spread
- spread 判定必须基于“实际舞台宽度”，而不是 window 宽度或外层容器宽度。

## 测试策略

- 纯逻辑单测（Vitest）：
  - spread 判定函数：`layoutMode → spread`
  - 舞台宽度/阈值相关逻辑（若抽出函数）
- 手工 smoke（由使用者执行）：
  - 正文选中 → 操作条出现 → 高亮/收藏/笔记正常
  - 边距点击翻页不影响正文选中
  - 沉浸 HUD 唤出/隐藏、翻页、退出稳定
  - 切换主题/护眼色不出现“回翻”观感
