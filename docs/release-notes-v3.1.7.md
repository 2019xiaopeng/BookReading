# v3.1.7 · 2026-11-25 · 字体渲染根治 + 布局修复

## 字体渲染（核心修复）

- **根治正文字体丢失**：epub.js 的主题注入此前在首章渲染前调用——iframe 尚未创建，样式表为空，字体/排版主题从未生效。本版在首章渲染完成后注入，并在每次章节切换时自动重新应用，**文字始终使用你选择的字体**
- 此前 dev 调试版正常是因为 Vite 初始化较慢碰对了时序；安装版初始化快，注入必然失败——本版从代码路径上根治，不再依赖时序

## 布局（v3.1.2 遗留修复）

- **侧边栏完整布局恢复**：v3.1.2 中误残留的窄窗 CSS 导致品牌标题消失、导航变居中孤立图标、底部按钮变 2×2 拉伸椭圆——本版全部删除，**任何窗口宽度锁定完整形态**
- **弹窗居中修复**：改用纯 grid 居中（不再依赖 transform），弹窗/详情/设置不再偏移右下
- **抽屉弹跳修复**：开/关设置、目录等右侧抽屉时阅读区不再弹跳
- **滚动条偏移修复**：弹窗打开锁定滚动时内容不再右移

## 字体切换防崩

- 切换正文字体不再白屏——加 try-catch 防御 + 路由级 ErrorBoundary 兜底（异常时显示"返回书架"按钮）

## 开发者

- dev 环境数据隔离：`npm run dev:isolated` 使用独立数据目录，不再影响正式安装版
- Vite 生产构建禁用 minify（防止 epub.js 内部被压缩器破坏）
