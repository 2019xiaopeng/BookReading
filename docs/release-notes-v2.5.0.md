# BookReading v2.5.0

性能根治 + 功能补齐 + 全新「碳墨刊头」界面。三个主题词：**快、够用、像一本印出来的书**。

## 性能（实测对比 v2.1.0，同机同库，10 秒滚动/20 步操作采样）

| 场景 | v2.1.0 → v2.5.0 |
|---|---|
| 书架滚动卡顿帧（61 本） | 11 → **0**（最长掉帧 394ms → 18ms） |
| 条漫连续滚动 | 卡顿 7 帧 → **0**（p95 帧间隔 24.3ms → 6.2ms） |
| 漫画翻页 ×20 最长掉帧 | 54ms → **12ms** |
| EPUB 拖字号整章重排耗时 | 0.3s → **0.1s**，拖动过程零白闪 |

- 封面全面走 480px 缩略档（启动不再整批原图过 IPC，存量自动后台补生成）
- 漫画页列表与压缩包句柄缓存、按显示尺寸降采样，翻完整本从 O(N²) 降为 O(N)
- 全部后端命令并发化；SQLite WAL + 索引
- EPUB 开书首显直达进度位置（不再先渲染第 1 章再跳）；厚书进度条就绪结果持久化（同字体字号二次开书秒就绪）
- 自定义字体真正注入正文（iframe @font-face + 字体就绪才排版）
- 窗口记住大小与位置

## 新功能

- 划选正文一键复制
- 漫画方向 / 双页 / 适配 / 条漫宽度 / 双页偏移**按书记住**（全局默认 + 书内覆盖）
- 阅读时长统计：书卡与详情显示「已读 X 小时」
- 标注与收藏摘录导出 Markdown（单书 / 全库）
- 书库搜索跨书架全库命中
- 字号快捷键 Ctrl+= / Ctrl+- / Ctrl+0
- 页面面板：打开定位当前页、页码直达
- 高亮原文与笔记分列显示（存量自动迁移，零丢失）

## 界面「碳墨刊头」（M2）

- 新默认主题**纸墨**（日间米白×碳墨）与**墨夜**（夜间碳墨），原有六主题全部保留，共 8 套
- 书架刊头大字排印 + 等宽统计列；工具行图标化（排序收纳下拉、密度三格分段）
- 书卡封面墨线描边、在读进度改为封面下缘 2px 墨线、悬停 ⋯ 菜单
- 印刷感细节：纸底噪点、分区尾注线、骨架 shimmer
- 阅读器顶/底栏纸墨毛玻璃；主题色即墨色（换主题=换墨）
- 小窗适配：720px 最小宽度三档断点，无横向滚动

完整批次记录见 `docs/superpowers/plans/`，更新日志见 `docs/CHANGELOG.md`。

## 升级说明

- 首次启动会自动为存量封面后台生成缩略档（约每本 1-3 秒，不卡界面）
- 数据库自动迁移（WAL、新表），升级前建议备份 `%APPDATA%\com.root.bookreading\db`
