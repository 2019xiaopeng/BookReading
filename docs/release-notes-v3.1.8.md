# v3.1.8 · 2026-11-25 · v3.1 系列字体/布局问题根治

## 根因修复（v3.1.0 起安装版专属）

- **找到并根治 v3.1.0 起安装版"字体平淡、排版异常、插图/logo 破版"的真因**：v3.1.0 为放行启动脚本引入了 CSP 安全策略，打包时 Tauri 又向其中追加了 nonce 标记——而按 CSP 规范，source 列表里出现 nonce 后内联样式授权（'unsafe-inline'）整体失效。阅读器（epub.js）的全部动态样式注入——主题纸墨色、正文字体栈、行距边距、图片缩放、书籍内嵌字体——被安全策略静默拦截，一个都不剩
- **为什么修了六个版本都没用**：调试版从不注入该策略，所以开发环境永远"正常"，时序类修复（3.1.3/3.1.7）与构建类修复（3.1.6）全部打偏。本版改用 CDP 直连安装版取证，一次锁定
- **修复方式**：移除该策略配置，回到 v3.0.1 的已知良好状态（本地应用 + 阅读器默认剥离书内脚本，安全姿态与已发布版本一致）。安装版实测：主题色、字体（含自定义字体与书籍内嵌字体）、行距边距、插图缩放全部恢复

## 随手修复

- **书库封面**：同一策略曾拦截部分封面图（asset 协议路径），本版一并恢复
