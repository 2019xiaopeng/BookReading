# BookReading v2.0.0

把一个文件夹塞满 epub、txt、漫画和 PDF，然后在三四个软件之间来回切换——这是很多 Windows 读者每天的日常。在线阅读器要账号、要联网、还可能下架你的书；专业漫画工具不管文字书；PDF 阅读器读不了小说的章节目录。BookReading 想解决的就是这一件事：一个本地优先的桌面应用，把四种格式装进同一个书架，进度、书签、笔记全部存在你自己的硬盘上。

## 核心特性

- **四格式统一阅读**：EPUB、TXT（自动识别 GBK 编码并按规则分章）、漫画文件夹 / CBZ、PDF，同一书架同一套交互
- **像纸书一样翻页**：翻页 / 滚动双模式，单双栏，RTL 日漫支持，翻页动画速度 150–600ms 随手调
- **六套主题 + 换字体**：从浅色到高对比暗色一键切换，正文可装自己的字体文件，背景图随心换
- **为漫画做的细节**：Webtoon 连续滚动、自动滚动（空格播放、方向键调速）、Ctrl+滚轮缩放锚定光标、条漫宽度三档
- **PDF 认真做了**：翻页与连续滚动双模式、窗口外页面自动停止渲染省内存、页书签、缩略图跳页
- **层级书架 + 标签 + 回收站**：书架无限层级拖拽归架，8 色标签 AND 筛选，删除先进回收站 30 天可反悔
- **批量导入不返工**：多选文件、整个父目录一键拆成漫画册、直接拖进窗口；自动查重，进度和失败原因逐本说清
- **阅读记录全在本机**：进度、书签、划线高亮、收藏句子、笔记，存本地 SQLite，无账号无云端无上传
- **存储自己管**：书库根目录可整体迁移到大盘，封面 / 背景 / 日志分类占用统计一键清理
- **顺手的小心思**：F11 全屏、Ctrl+D 沉浸锁定、章内页码、书内搜索带章节和百分比、回收站保留期自选

## 安装

1. 下载 `bookreading_2.0.0_x64-setup.exe`（本页 Assets）
2. 双击运行，按提示完成安装（内置 WebView2 离线安装器，无需联网另装组件）
3. Windows SmartScreen 首次提示时选择"仍要运行"（应用未购买代码签名证书）

系统要求：Windows 10 1809+ / Windows 11，x64。

## 首次使用

1. **导入**：点侧栏"导入"，或直接把文件 / 文件夹拖进窗口。漫画推荐把每本书放进独立子文件夹后选父目录批量导入。
2. **整理**：书库空白处右键新建书架，把书拖进去；给常读的书打标签、加置顶。
3. **舒适**：顶栏调色盘换主题；阅读中打开右侧设置调整字号、行距、字体和翻页动画。

## 从 1.x 升级

- 直接安装新版覆盖即可，数据无需迁移。
- 旧版的"分组"会在首次启动时自动转换为根级书架，书和备注原样保留。
- 数据仍存放在原位置（`%APPDATA%/com.root.bookreading`），进度、书签、高亮、收藏不受影响。
- 新版回收站生效：删除的书先进回收站（默认保留 30 天），可在回收站页恢复或彻底删除。
