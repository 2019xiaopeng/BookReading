## v2.5.0 · 开发中（性能根治 + 功能补齐 + M2「碳墨刊头」改版）

### 批次 20 · 后端性能与管线（2026-10-30）
- **async 化**：全部 40+ Tauri 命令并发执行，多页读盘不再阻塞主线程与 IPC

## v2.0.0 · 2026-10-28

首个公开发布版。从单格式 EPUB 阅读器起步，经 2026 年 5 月基础建设与 10 月路线图十四个批次迭代，成为覆盖 EPUB / TXT / 漫画 / PDF 的 Windows 桌面全格式阅读器。以下按批次归纳，完整过程见 `docs/superpowers/plans/`。

### 发布前基础（2026-05）
- **EPUB 阅读**：Tauri + React 骨架，书库导入 / 删除、目录、进度、书签、划线高亮、全文搜索（IndexedDB 缓存索引）
- **收藏系统**：收藏书籍与句子（文本快照 + CFI 定位），收藏页搜索筛选跳转；Windows 安装包 CI
- **存储加固**：文件访问收敛到 AppData/library，相对路径持久化，tmp + rename 原子写入，修复封面不显示与删书失败
- **交互修复**：翻页热区收敛到边距、主题切换不回翻、多选 EPUB 顺序导入
- **界面重设计**：微信读书风 App Shell + 阅读页抽屉面板（目录 / 书签 / 高亮 / 收藏 / 搜索 / 设置）

### 批次 1 · 文字书补全（2026-10-26）
- **TXT 导入**：编码探测（BOM/UTF-8/UTF-16/GBK 回落），legado 规则池分章 + 无命中兜底切块 + 超长章拆分，TXT 转 EPUB3 全链路复用
- **搜索增强**：结果带章节标题与百分比定位
- **书架管理**：置顶 / 分组 / 备注，分组筛选与排序；无封面书改文字封面卡
- **导入校验**：魔数嗅探分流，错误消息带源路径与 GBK 指引

### 批次 2 · 漫画（2026-10-26）
- **漫画/图片书**：图片文件夹（原地引用）与 CBZ（解包临时目录）两种来源
- **阅读器**：适高 / 适宽 / 原始三档适配、单双页、RTL、横图跨页、Webtoon 连续滚动
- **页面面板**：懒加载缩略图、当前页高亮、点击跳页

### 批次 3 · 滚动模式与主题（2026-10-26）
- **滚动模式**：paginated / scrolled 直切，CFI 进度自动恢复，滚动下翻页动画禁用
- **六主题**：浅色 / 纸黄 / 护眼绿 / 灰 / 暗色 / 高对比暗色，全端对比度达 AA
- **自定义背景图**：阅读纸面 cover 渲染 + 实色可读性纱，暗色下不透底

### 批次 4 · 十项实测反馈大修（2026-10-27）
