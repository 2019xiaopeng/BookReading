# 更新日志

## v2.0.0 · 2026-10-28

首个公开发布版。从单格式 EPUB 阅读器起步，经 2026 年 5 月基础建设与 10 月路线图十四个批次迭代，成为覆盖 EPUB / TXT / 漫画 / PDF 的 Windows 桌面全格式阅读器。以下按批次归纳，完整过程见 `docs/superpowers/plans/`。

### 发布前基础（2026-05）
- **EPUB 阅读**：Tauri + React 骨架，书库导入 / 删除、目录、进度、书签、划线高亮、全文搜索（IndexedDB 缓存索引）
- **收藏系统**：收藏书籍与句子（文本快照 + CFI 定位），收藏页搜索筛选跳转；Windows 安装包 CI
- **存储加固**：文件访问收敛到 AppData/library，相对路径持久化，tmp + rename 原子写入，修复封面不显示与删书失败
- **交互修复**：翻页热区收敛到边距、主题切换不回翻、多选 EPUB 顺序导入
- **界面重设计**：微信读书风 App Shell + 阅读页抽屉面板（目录 / 书签 / 高亮 / 收藏 / 搜索 / 设置）

### 批次 1 · 文字书补全（2026-10-26）
- **TXT 导入**：编码探测（BOM/UTF-8/UTF-16/GBK 回落），legado 规则池分章 + 无命中兜底切块 + 超长章拆分，TXT 转 EPUB3 全链路复用
- **搜索增强**：结果带章节标题与百分比定位
- **书架管理**：置顶 / 分组 / 备注，分组筛选与排序；无封面书改文字封面卡
- **导入校验**：魔数嗅探分流，错误消息带源路径与 GBK 指引

### 批次 2 · 漫画（2026-10-26）
- **漫画/图片书**：图片文件夹（原地引用）与 CBZ（解包临时目录）两种来源
- **阅读器**：适高 / 适宽 / 原始三档适配、单双页、RTL、横图跨页、Webtoon 连续滚动
- **页面面板**：懒加载缩略图、当前页高亮、点击跳页

### 批次 3 · 滚动模式与主题（2026-10-26）
- **滚动模式**：paginated / scrolled 直切，CFI 进度自动恢复，滚动下翻页动画禁用
- **六主题**：浅色 / 纸黄 / 护眼绿 / 灰 / 暗色 / 高对比暗色，全端对比度达 AA
- **自定义背景图**：阅读纸面 cover 渲染 + 实色可读性纱，暗色下不透底

### 批次 4 · 十项实测反馈大修（2026-10-27）
- **封面稳定**：会话缓存 + 退避重试 + 失败回补，根治封面随机消失
- **主题修复**：epub 主题色统一收口，根治暗色文字消失、行距不生效、单双栏切换错乱
- **选区气泡**：选中即现高亮 / 收藏 / 笔记气泡，替代弹窗
- **进度条**：可拖动 + 键盘 ±1%，大书 locations 超时自动重试
- **书架**：重命名、hover 浮出菜单、右键菜单、HTML5 拖拽入组，window.prompt 全部换为应用内对话框

### 批次 4.5 · 全局主题与背景（2026-10-27）
- **主题单一事实源**：主题记忆根治，首帧不闪白，壳 / 阅读器 / 漫画三端同源即时切换
- **全局背景**：背景图升级应用级，单槽缓存无泄漏

### 批次 5 · 阅读体验深化（2026-10-27）
- **页码**：章内页码徽标，单页右下 / 双页两角，随字号分栏自适应
- **沉浸锁定**：状态机重做，锁定全藏 + Ctrl+D 切换 + 3s 自动隐栏
- **整页动画**：slide 档改纸面整页两段式平移，防连翻卡死
- **漫画**：条漫宽度三档 + 自定义、Ctrl 缩放、页书签、收藏接线
- **书库**：密度三档、分组书架导航、自定义封面、父目录批量导漫画

### 批次 6 · P0 与行为修复（2026-10-27）
- **批量导入**：修复单本入口误传父目录导致的 P0 失败，逐本汇总
- **工具栏**：顶 / 底 48px 热区唤出，overlay 零重排；锁定态常驻退出控件
- **阅读字体**：宋 / 黑 / 楷 / 仿宋 / 默认五档预设
- **封面显示**：object-fit contain 不裁切变形

### 批次 7 · 产品化打磨（2026-10-27）
- **设计令牌**：主题块外零字面量颜色，六主题对比全达标
- **状态四件套**：空 / 加载 / 错误态接入全部页面，17 处原生 alert/confirm 清零
- **无障碍**：focus-visible / reduced-motion 全仓终查，书卡键盘可达
- **细节**：favicon、标题、密度特大第四档

### 批次 8 · 层级书架与回收站（2026-10-27）

- **回收站**：软删可恢复，7/30/永不保留期，启动自动清过期
- **批量模式**：浮动批量条（移动 / 收藏 / 删除 / 全选），侧栏书架树

### 批次 9 · 标签系统与详情页（2026-10-27）

- **详情页**：编辑标题 / 作者 / 简介，统计行（格式 / 大小 / 页数 / 进度 / 书架路径），封面点击更换
- **阅读状态**：未读 / 在读 / 已读自动判定 + 筛选

### 批次 10 · 存储管理与导入增强（2026-10-28）
- **存储**：库根可迁移（空间预检、失败回滚）、分类占用统计、一键清理缓存
