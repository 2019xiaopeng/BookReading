# BookReading v2.7.0

库管理与阅读体验大版本：回收站批量、收藏页全面升级、阅读状态可自定、大部头修复、应用内更新。主题词：**删得干净、状态随心、大书能开、自己会更新**。

## 书库管理

- **回收站批量操作**：多选/全选/批量恢复/批量彻底删除/批量从电脑删除——一次确认处理 N 本，不再逐本二连击
- **收藏页全面升级**：与书架同款书卡（⋯ 菜单/右键/拖到书架归档/密度/进度墨线）、批量取消收藏与移动、页内排序、摘录右键（复制/定位/删除）
- **书架（文件夹）增强**：置顶书浮到全网格最顶；文件夹独立排序（默认/书名/书数）；嵌套书架显示含子孙的总数；侧栏树同款计数
- **搜索与文件夹联动**（Windows 资源管理器式）：搜索时文件夹按名称/含命中过滤并显示"N 命中"角标；命中的书卡显示所属书架路径；隐藏无关架与新建卡
- **导入三模式**：复制入库（默认）/ 移动（源文件进回收站，不双存）/ 原地引用（EPUB·PDF 保留在你自己的目录，库里只存引用）——设置中切换
- 右键书卡与 ⋯ 菜单完全同款；书详情补置顶/收藏入口
- **关闭行为记忆**：✕ 三选中勾「记住我的选择」不再打扰；设置中随时改回
- 数据库启动滚动备份（自动保留最近 3 份）

## 阅读器

- **修复 v2.6 回归**：分页模式下书内插图（章节 logo/装饰图）永不加载的懒加载缺陷；顺带修复 v2.5 遗留的自定义字体注入管线错挂（v2.6 已修，本版验证收尾）
- **大部头打开守卫**：>64MB 且无优化副本的书不再硬开冻结——显示「正在生成优化副本」进度，完成后自动开书；后台补生成改为大书优先
- **优化副本 v2**：剥离内嵌音视频（阅读副本更小更快）、>300KB 图片字节阈值重编码、移除书页内失效的视频标签
- **书内插图点击放大**：全屏查看 + 滚轮缩放 + 拖拽平移 + 双击复位
- **媒体面板**：含音视频的书在抽屉出现「媒体」页签——逐条点播，不再让 58MB 视频拖死整本书
- **阅读状态自定**：菜单直接标 未读/在读/已读（手动优先），自动推导改为"打开过=在读"；"已读 X"不满 1 分钟也显示
- **阅读计时修正**：窗口最小化/切后台不再计入阅读时长
- **偏好默认值**：设置面板一键「设为我的默认」/「本书恢复默认」（漫画与 EPUB 同款）
- **主题跟随系统**：新增"自动"主题（浅色纸墨/深色墨夜随系统切换）
- 阅读器抽屉记住上次页签；标注/书签面板一键清空

## 体验细节

- 书库 Ctrl+F 聚焦搜索；回收站支持键盘 Delete 删除
- 批量操作轻提示（"已移动 N 本"）；导入进度提示大部头需时
- **应用内更新**：设置→关于「检查更新」，一键下载安装（自动尝试本地代理）；启动可静默检查（红点提醒，不打扰）；发布页一键直达
- 修复生产环境前端日志不落盘（CSP）；升级后首次启动展示新版本亮点

- CI 流水线上线：今后 tag 推送自动云端构建发布
