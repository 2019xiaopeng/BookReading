# v2.8.0 开发计划（草稿 · 待补充）

> v2.7.0 已发布（2026-11-19，CI 流水线首秀）。本文为 v2.8.0 需求池，由用户陆续补齐。

## 一、侧栏书架树折叠（2026-11-19 用户提出，已设计待实施）

**诉求**：书架越来越多，侧栏树会超出可视高度——需要折叠/展开。

**设计**：

| # | 项 | 方案 |
|---|---|---|
| S-1 | 折叠交互 | 有子书架的树节点（wr-nav-group-btn）行尾加 ▸/▾ 旋转小箭头（或点行名=进入、点箭头=折叠，两区分离防误触）；折叠状态存模块级 Map（会话内）+ settings 键 `shelf_collapsed`（跨会话，JSON 数组存折叠的 shelf id） |
| S-2 | 全部收起/展开 | 侧栏树顶部（快捷 chips 下方或树标题行）加「全部收起 / 全部展开」文字小钮 |
| S-3 | 长树滚动 | .wr-nav-groups 超高时 overflow-y:auto（现无上限，靠壳层滚动——核对两处滚动嵌套的手感，取自然的一层） |
| S-4 | 计数联动 | 折叠的架：递归计数仍上卷到父行显示（K-4 的 rollupShelfCounts 已支持，纯展示问题） |

**验收**：折叠后子架隐藏且计数并入父行；重启保持折叠态；全部收起→树只有根级；箭头点击不触发进入书架。

## 一·二、v2.8 补充三件（2026-11-19 用户确认）

| # | 项 | 方案 |
|---|---|---|
| R-1 | **继续阅读入口** | 书架根视图顶部一张"上次在读"快捷卡：封面缩略 + 书名 + 进度墨线/百分比 + 一键进入（数据源=全库 last_opened_at 最新且未读完；无在读时不占位）。点击进入阅读页；卡片右缘小 ✕ 可 dismissing（本次会话不再显示）。低优先做视觉——先复用 wr-book-card 单卡横排样式 |
| R-2 | **Shift 范围多选** | 书架/回收站/收藏页三处统一：普通点击=切换选中；Shift+点击=从上次点击项到当前项范围全选/全不选（以可见过滤列表为准）；记录 lastClickedId 每页一份。与现有批量条/全选钮正交共存 |
| R-3 | **目录当前章高亮+滚动定位** | TOC 抽屉：当前章（spineIndex 对比）data-active 高亮（accent 左条+加粗）；抽屉打开时 scrollIntoView({block:"center"}) 滚到当前章（同 PagesPanel v2.5 的做法） |

**验收**：读完一本书自动换下一张"继续阅读"；Shift 选 50 本回收站一次清；350 章书开目录直接看到当前章在高亮处。
