## 一、头号体验项

### V-1 翻页动画矩阵——对标 Wenku8_Flutter 六效果（2026-11-25 依参考源码定稿，替换原"双缓冲快照+3D 折影"方案）

**参考实现**：`github.com/mikufoxxx/Wenku8_Flutter`（用户手机在用的安卓版；本地克隆 `F:\tmp\wenku8_flutter`）
核心三文件：`lib/reader_sheet_motion.dart`（动画渲染，299 行）/ `lib/reader_paged_view.dart`（编排，2007 行）/ `lib/reader_preferences.dart`（效果枚举 ReaderPageEffect）。

**四条核心原理**（源码实证）：
1. **双 live 叶片，零截图**：翻页瞬间新旧两页同时保留（各裹 RepaintBoundary），动画=对 live 页施加**合成层**操作（ClipPathLayer/TransformLayer/OpacityLayer）——不做 DOM 克隆、不逐帧截图。源码注释原话："A fold is two complementary clips and a paper crease, not two fading text planes or a screenshot captured on every frame."
2. **单一进度源**：全局唯一 `progress∈[0,1]` + `direction(±1)` 驱动所有效果；progress 是滚动手势的纯函数（`_scrubTurn`：拖动位移/页宽 → 拖动即预览，松手滚动物理收尾到 0 或 1）——**天然可抢占**（连按/反向重拖无需 clearTimeout 补丁，progress 永远由当前手势重算）
3. **效果=同一 progress 下的纯画法差异**（见下表，可整组抄参数）
4. **章界预排版（edge slot）**：相邻章首页提前排版挂在 PageView 轨道两侧边缘槽位（itemCount=本章页数+2），跨章动画翻的是**真实下一章内容**，动画完成后帧回调才真正换章

**六效果画法**（数值全为相对页宽 w、包络 e=sin(π·progress)）：
| 效果 | 画法 |
|---|---|
| 无动画 | 直接跳变 |
| 平移 | 轨道原生滚动：新旧两页同排随位移整体平移（无特效层，PageView 自带） |
| 覆盖 | 新页携**不透明纸底**自边缘滑入压住静止旧页（位移 = w·(1-t)）；前缘软阴影带宽 min(22px, 5.5%w)、峰值 alpha 0.16·e，只投在下方旧页露出侧 |
| 渐隐 | 交叉淡化（旧 1-t / 新 t）；**每叶背后先铺不透明纸底**，防两页文字透叠重影 |
| 纸页翻动 | 两互补**弧形 clip**（三次贝塞尔边缘）沿移动折痕分界（折痕 x=w·(1-t)）；折弯 bend≤min(24px,4.5%w)、折页宽 fold≤min(28px,6.5%w) 均乘 e；折痕阴影带 spread≤min(26px,7%w) alpha≤0.3·e；折页高光=三段渐变（暗→亮→纸色）模拟纸背受光。**无 WebGL/着色器/3D 变换**——纯 2D clip+渐变 |
| 段落接续 | 段落级错峰平移（该 App 默认效果；本库**可选低优先级**） |

**落地架构（2026-11-25 用户裁定：只做 EPUB，漫画/PDF 不做）**：
1. **GhostView 双容器**：叶片=iframe 的**宿主容器**（对宿主 div 施 transform/clip 不触发 iframe 内部重排）。把 Phase 1 已落的"先画完再滑入"（dc87760）升级为完整双容器：翻页前 GhostView（同 book 第二个 rendition）预渲染目标页隐藏待命 → 动画期新旧两容器同场 → 动画毕销毁 Ghost 复位（跨章时 Ghost 直接转正为主视图，免去主视图重渲染闪变）。章内翻页=Ghost 滚同章相邻栏；跨章=Ghost 预渲染邻章（对标 edge slot），超时/失败降级渐隐
2. **`PageTurnLayer` 宿主特效层**（新组件）：输入 (oldLeaf, newLeaf, effect, direction, progress)，输出上表画法；rAF 驱动；progress 源可插拔（定时器先行，手势驱动后置统一）

**设置项**：翻页效果六选一（段落接续可选）+ 既有 150–600ms 速度滑块复用（每效果独立时长档，对标其 `pageSpeed.durationFor(effect)`）。

**批次**：① EPUB 双容器 + 无/平移/覆盖/渐隐 → ② 纸页翻动（弧形 clip+折痕）→ ③ 手势驱动统一（progress=拖动纯函数，替换连按抢占补丁）→ ④ 跨章预渲染转正（可选，渐隐兜底）

**验收**：350 章长书连翻 100 次零闪白零重影；深浅纸色主题下阴影/折痕颜色正确（暗纸 alpha 上调至 .3/加深 8–15%，对标源码 luminance<.15 分支）；快速连按/反向连按无卡死无跳变；跨章动画有真实内容非纸色空页；效果切换即时生效并记忆。

### V-3 设置独立大页面 + 开场动画（F-6 决议）

- **开场动画 ≤ 600ms**（不要 1.5s）——桌面软件最大爽感是"秒开"，超 1 秒每天打开都觉得拖沓；做丝滑纸墨淡入即可
- **设置页面八分区**：外观 / 阅读 / 书库 / 云书架 / 网络与更新 / 快捷键 / **漫画增强**（新增）/ 关于
- 与 V-2 组件基座同期实施（依赖 Radix Tabs/NavigationMenu）

### V-5 自制书向导（F-5 决议）

- **单页表单 + 左右分栏**（不做逐步向导——桌面工具不需要"下一步→下一步"）
- 左栏：书名/作者输入、封面选择、分章规则（内置 3 套常用正则预设 + 自定义正则输入）
- 右栏：**实时章节目录树预览**（识别出的卷/章所见即所得）
- 一键生成 EPUB 直接入库（复用 txt_to_epub + import_book 管线）
- **插图编排留 3.3**

## 三、功能项

### V-6 wenku8 增量更新替换（自旧候选池拉入）

**现状**：连载书显示"有新章"徽标，但要重拉整本太浪费。
**修法**：只拉取新增章节 → 追加进本地 EPUB（zip 尾部插入新 XHTML + 更新 OPF/spine/NCX）→ 阅读进度按章节索引迁移（CFI 前缀匹配，新增章不影响已有进度）。
**验收**：有新章的书点"更新"→ 只下载新增章节（进度条显示 N/M 章）→ 完成后直接继续阅读，进度不丢。

### V-7 wenku8 云端全站搜索（自旧候选池拉入）

**现状**：只能拉取已收藏的书架。
**新增**：接入 `action=search` 全站检索——在云书架页直接搜书名/作者 → 结果列表（封面+元信息）→ 点详情 → 拉取入库。
**入口**：云书架搜索框语义升级（本地过滤 ↔ 云端搜索双模式切换，或搜索结果合并展示）。

### V-8 自动整理归类（F-3 决议）

- **一键整理 + 预览确认**（不做全自动静默——360 本书乱改分类容易出意外）
- 预览弹窗展示"将把 X 本书移入漫画架、自动生成 Y 个作者标签"
- 入口：设置页 + 书库工具栏
- 规则内置不可配（YAGNI）

### V-9 多实例加固（F-7 决议）

- **文件锁**防同时导入（两个实例同时跑 import_book 竞态）
- **托盘图标去重**（第二个实例不重复创建托盘）
- 书卡右键新增**"在新窗口中打开"**（spawn 新进程开同一本书，方便双开对比）
- 不重构为单进程多窗口

## 四、基础架构

### V-10 前端热更新 OTA（F-9 决议）

- **托管**：Cloudflare Pages（国内稳 + 免费 + Git push 自动部署）
- **检测**：启动时（+运行中每 4h）
- **Rust 侧**：`register_uri_scheme_protocol` 自定义协议——优先 serve 本地缓存目录，空/损坏回退内嵌资源
- **刷新**：下载解压到缓存 → `location.reload()` 无感刷新

- **版本锁红线（用户强调）**：
  - 热更新包**严格绑定当前 Rust 后端版本号**
  - 前端 diff 涉及 `#[tauri::command]` 变更 → 热更新通道**自动跳过**，强制提示走整包更新
  - 防新前端调老 exe 里不存在的接口导致白屏崩溃
  - CI 路径过滤自动判定：`src-tauri/**` 有 diff → 走 tag 流程；仅 `src/**` → 走 Pages 部署

### V-11 断点续传（3.1 遗留）

- 更新包 5MB 虽小但仍可能断网——Range 请求续传（updater 插件不支持，需自实现或 patch）


### V-12 更新安装包临时文件自动清理

- `run_update_installer` 启动安装器后延迟 30s 自动删 `%TEMP%ookreading-update\`（安装器已读入内存，删不影响安装）
- 热更新通道（V-10）天然无此问题——前端包直接解压到应用缓存，不产生安装包文件


### V-13 漫画/PDF 翻到最后一页提示（2026-11-24 用户提出，杂项）

**现象**：漫画翻到最后一页再翻无反馈，不确定是不是真到底了。
**方案**：到达末页再往后翻时，屏幕正中弹一个**极小的淡入淡出提示**（如「已是最后一页」），1 秒自动消失、不阻挡交互。EPUB 同理（末章再翻显示「已是最后一章」）。样式走碳墨 token（纸底墨字小胶囊，与 toast 同语言但更轻）。
**防骚扰**：连续触发只重置倒计时不叠弹（同一 key 节流 2s）。
