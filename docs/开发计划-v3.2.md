## 一、头号体验项

### V-1 翻页闪白修复 + 3D 纸页折影仿真翻页（2026-11-24 用户提出，**头号体验项**）

**Bug 现状**：翻页时先闪一下空白页——程序清空当前画面 → 计算排版/解码下一张 → 再画出来，CSS 动画在"旧图刚清掉、新图还没画完"的空窗期触发，动画翻的是空白画布。

**修法：双缓冲视觉快照**
- 翻页触发瞬间：将当前页**定格为顶层覆盖层**（截图/DOM 克隆）
- 底层新页面完全渲染就绪后：再执行翻页动画
- 动画完成后：移除覆盖层——彻底消除空窗闪白

**3D 纸页折影**：
- **不用 WebGL/Three.js**——纯 CSS `perspective` + `rotateY` + 动态渐变折痕阴影
- 单页模式：左边缘为轴（书页从右往左翻，右边缘微卷）
- 双页模式：屏幕中缝为轴（左右两页同时翻，中缝折痕加深）
- 折痕阴影随翻页角度实时渐变（0° 无阴影 → 90° 最大 → 180° 消失）
- **连续快速按键自动中断动画**：新翻页请求到达时立即完成当前动画跳到目标页，防卡顿
- 与现有翻页模式（无/淡入/平移）并存：设置里新增"纸页折影"选项

**验收**：350 章长书连续翻页 100 次零闪白；快速连按不卡顿；八主题下折影阴影颜色正确；双页偏移/RTL 兼容。

## 二、组件与界面（F-1 + F-6 + F-8 合并设计）

### V-2 Radix 组件基座引入（F-1 决议）

- **引入四件**：Menu（右键/更多菜单）、Dialog（弹窗）、Select（下拉框）、**Tooltip**（极轻量，为 F-8 窄窗图标栏悬停提示服务）
- 全局 focus ring 颜色对齐碳墨主题变量（`--wr-accent` 派生，八主题同步）
- 替换现有手搓 wr-menu / 对话框 / ShelfPicker 的行为层（视觉层保留碳墨 token）
- **不换脚手架、不整库替换**（脚手架结论已锁）

### V-3 设置独立大页面 + 开场动画（F-6 决议）

- **开场动画 ≤ 600ms**（不要 1.5s）——桌面软件最大爽感是"秒开"，超 1 秒每天打开都觉得拖沓；做丝滑纸墨淡入即可
- **设置页面八分区**：外观 / 阅读 / 书库 / 云书架 / 网络与更新 / 快捷键 / **漫画增强**（新增）/ 关于
- 与 V-2 组件基座同期实施（依赖 Radix Tabs/NavigationMenu）

### V-4 窄窗体系性设计（F-8 决议，含用户否决项）

- **先改书库页 + 阅读页**两个高频页面，其余页窄窗概率低后续跟进
- 侧栏：<800px = 56px 图标栏（根级+激活链）；<600px 转抽屉
- **搜索框规则（用户否决"全宽统一图标化"）**：
  - **≥900px**：保持展开常驻大胶囊搜索栏（宽屏大气直接）
  - **<900px**：自动收起为点击展开的搜索图标
  - Ctrl+F 任何宽度直接聚焦唤起
- 底部四钮：<800px = 2×2 图标宫格

### V-5 自制书向导（F-5 决议）

- **单页表单 + 左右分栏**（不做逐步向导——桌面工具不需要"下一步→下一步"）
- 左栏：书名/作者输入、封面选择、分章规则（内置 3 套常用正则预设 + 自定义正则输入）
- 右栏：**实时章节目录树预览**（识别出的卷/章所见即所得）
- 一键生成 EPUB 直接入库（复用 txt_to_epub + import_book 管线）
- **插图编排留 3.3**

## 三、功能项

### V-6 wenku8 增量更新替换（自旧候选池拉入）

**现状**：连载书显示"有新章"徽标，但要重拉整本太浪费。
**修法**：只拉取新增章节 → 追加进本地 EPUB（zip 尾部插入新 XHTML + 更新 OPF/spine/NCX）→ 阅读进度按章节索引迁移（CFI 前缀匹配，新增章不影响已有进度）。
**验收**：有新章的书点"更新"→ 只下载新增章节（进度条显示 N/M 章）→ 完成后直接继续阅读，进度不丢。

### V-7 wenku8 云端全站搜索（自旧候选池拉入）

**现状**：只能拉取已收藏的书架。
**新增**：接入 `action=search` 全站检索——在云书架页直接搜书名/作者 → 结果列表（封面+元信息）→ 点详情 → 拉取入库。
**入口**：云书架搜索框语义升级（本地过滤 ↔ 云端搜索双模式切换，或搜索结果合并展示）。

### V-8 自动整理归类（F-3 决议）

- **一键整理 + 预览确认**（不做全自动静默——360 本书乱改分类容易出意外）
- 预览弹窗展示"将把 X 本书移入漫画架、自动生成 Y 个作者标签"
- 入口：设置页 + 书库工具栏
- 规则内置不可配（YAGNI）

### V-9 多实例加固（F-7 决议）

- **文件锁**防同时导入（两个实例同时跑 import_book 竞态）
- **托盘图标去重**（第二个实例不重复创建托盘）
- 书卡右键新增**"在新窗口中打开"**（spawn 新进程开同一本书，方便双开对比）
- 不重构为单进程多窗口

## 四、基础架构

### V-10 前端热更新 OTA（F-9 决议）

- **托管**：Cloudflare Pages（国内稳 + 免费 + Git push 自动部署）
- **检测**：启动时（+运行中每 4h）
- **Rust 侧**：`register_uri_scheme_protocol` 自定义协议——优先 serve 本地缓存目录，空/损坏回退内嵌资源
- **刷新**：下载解压到缓存 → `location.reload()` 无感刷新

- **版本锁红线（用户强调）**：
  - 热更新包**严格绑定当前 Rust 后端版本号**
  - 前端 diff 涉及 `#[tauri::command]` 变更 → 热更新通道**自动跳过**，强制提示走整包更新
  - 防新前端调老 exe 里不存在的接口导致白屏崩溃
  - CI 路径过滤自动判定：`src-tauri/**` 有 diff → 走 tag 流程；仅 `src/**` → 走 Pages 部署

### V-11 断点续传（3.1 遗留）

- 更新包 5MB 虽小但仍可能断网——Range 请求续传（updater 插件不支持，需自实现或 patch）

## 五、3.3+ 延后（不进 3.2）

| 项 | 理由 |
|---|---|
| mobi/azw3（libmobi FFI） | C 库打包/CI 风险高，别拖慢 3.2 |
| 在线流式阅读 | 大工程，整本拉取已论证更优 |
| 试读模式 | 依赖增量更新先落地 |
| 云写操作（加删签到） | 使用频率不高 |
| 自制书插图编排 | 等 V-5 向导跑通后 3.3 |
| 词典/报告图/背景轮换/TTS二期 | 各自独立小件按需穿插 |
| 极品家丁 P2 | 上游 quirk |
