## 二、协议（已验证）

### 端点与请求
- `POST https://wenku8-relay.mewx.org/`（根路径，注意不是 /android.php）
- Body：`&appver=<magic>&request=<base64(action串)>&timetoken=<毫秒时间戳>`（**开头有 &**；base64 标准、trim）
- Headers：`Content-Type: application/x-www-form-urlencoded; charset=UTF-8`、`Accept-Encoding: gzip`、UA `Dalvik/2.1.0 (Linux; U; Android 7.1.2; unknown Build/NZH54D)`
- 登录后请求带 `Cookie`（响应 Set-Cookie 合并保存；errcode 4 = 需重登）

### appver 签名（60 秒窗口，按分钟缓存）
```
minute  = epoch_ms / 60000
payload = "1.29|digital-bento|" + minute
digest  = hex(HMAC-SHA256(key="digital-bento", msg=payload))
appver  = "1.29-digital-bento-" + digest[12..20]   // 8 个 hex 字符
```
实测 2026-11-20 通过（来源：aluo96078/shinsou_plugin 逆向，与 MewX libcpp.so 行为一致）。

### action 串（request 参数 = base64(明文)）
| 用途 | action 明文 | 返回 |
|---|---|---|
| 登录 | `action=login&username=<urlenc>&password=<urlenc>`（邮箱 `loginemail`） | 纯文本 `"1"` 成功 + Set-Cookie；`"2"`用户名错 `"3"`密码错 |
| 云书架 | `action=bookcase&do=list` | XML `<book aid="3988" />` 每行一本（仅 aid） |
| 书架(富) | `action=bookcase` | XML `<book aid=".." date="2026-08-23">`（App 未用，我们用一个即可——**用 `do=list` 版**，稳） |
| 书籍信息 | `action=book&do=bookinfo&aid=<aid>&t=0` | XML `<data name="Title" value="..">` 等（Title/Author/BookStatus/LastUpdate/LatestSection cid/TotalChapters? 以实测为准） |
| 简介 | `action=book&do=intro&aid=<aid>&t=0` | 纯文本 |
| 目录 | `action=book&do=list&aid=<aid>&t=0` | XML `<volume vid="..">卷名<chapter cid="..">章名</chapter></volume>` |
| 章节正文 | `action=book&do=text&aid=<aid>&cid=<cid>&t=0` | UTF-8 纯文本（首行自带章名，拼装时剥掉） |
| 封面 | 无需 API | `http://img.wenku8.com/image/<aid/1000>/<aid>/<aid>s.jpg` 直链 |

errcode：0 请求错误 / 1 成功 / 2 用户名错 / 3 密码错 / 4 未登录 / 5 已在书架 / 6 书架满 / 7 不在书架。

## 三、工程设计

### Rust（`src-tauri/src/commands/wenku8.rs`，新增）
- 常量：RELAY_URL、UA、APPVER 前缀/magic；`endpoint()` 单点可切换（降级铺垫）
- `magic_appver(minute: i64) -> String`：HMAC-SHA256（新增 crates：`hmac="0.12"`、`sha2="0.10"`），按分钟缓存（static Mutex）
- HTTP：reqwest blocking **跑在专用 std::thread**（v2.7 教训：blocking 在 Tauri async 线程死锁）；cookie 存 settings 表 key `wenku8.cookie`；失败重试 1 次；并发下载章节限 4（信号量/分批）
- 命令（全部 `#[tauri::command(async)]`，内部 spawn_blocking）：
  - `wenku8_login(user, pass) -> Wenku8LoginResult{ ok, errcode, message }`（成功后存 `wenku8.user`/`wenku8.pass`/`wenku8.cookie`）
  - `wenku8_status() -> Wenku8Status{ hasSaved, username }`
  - `wenku8_bookshelf() -> Vec<Wenku8ShelfBook{ aid: i64, name: Option<String>, date: Option<String> }>`（`bookcase&do=list`；name 由前端懒取，后端不做 N+1）
  - `wenku8_book_info(aid) -> Wenku8BookInfo{ aid, title, author, status, lastUpdate, latestCid, chapterCount? }`（bookinfo XML）
  - `wenku8_download(aid) -> Wenku8DownloadResult{ bookId, title, chapters }`：目录→逐章 text（并发4，emit `wr:wenku8-progress` {aid,done,total}）→拼 TXT（`卷名 章名\n\n正文`，剥 API 自带标题行）→写 appdata 临时文件→复用现有导入管线（与 import_book 同路：入当前书架/默认书架）→删临时文件
  - 会话失效（errcode 4）：自动用存的账密重登一次再重试
- 测试：magic_appver 固定 minute 断言；bookcase/bookinfo/目录 XML 解析（roxmltree，fixture 内嵌）；TXT 拼装格式断言。无网络测试。

- 侧栏加「云书架」入口（viewKey 加 `cloud-shelf`；图标 cloud/book；与收藏页同级）
- `src/pages/CloudShelfPage.tsx`：

  - 已登录：书卡网格（懒加载 name/封面/日期，会话内 Map 缓存；封面 `<aid>s.jpg` 直链，onerror 占位）；每卡「拉取到书库」按钮 → 进度条（听 `wr:wenku8-progress`）→ 完成后 toast + 可跳书架
  - 顶部刷新按钮；下载中防重复点击
- 测试：CloudShelfPage 组件测试（mock invoke wrapper：未登录态/列表态/下载进度）、wenku8.ts wrapper 映射

### 验收（dev 构建，需用户真实账号，用户自己在应用里输入）
1. 登录：错误密码→提示「密码错误」；正确→登录成功状态保持（重启应用仍在）
2. 云书架列出真实书目（书名/封面/日期正确）
3. 拉取一本短书：进度推进→入库→阅读器打开能读、分章正确
4. 会话过期自动重登（手动清 cookie 设置后拉书架）
5. 断网/relay 失败：错误提示可读，不崩
